# ElytrixCemetery — ивент «Кладбище»

Плагин для Spigot/Paper. Координаты и мир задаются в `config.yml`; при запуске используется схема `plugins/ElytrixCemetery/schematics/cemetery.schem`, если она есть, иначе кладбище генерируется процедурно. Общая голограмма события отключена, а над могилами остаются отдельные прозрачные голограммы.

## Основные механики

- **Могилы:** раскопка лопатой требует 20 завершённых циклов ломания. Удары, ПКМ и клики сами по себе прогресс не увеличивают. Во время раскопки ActionBar показывает оставшееся число циклов вместо общей статистики. Любые блоки в вертикальной колонне над могилой можно убрать; остальные блоки защищённой территории нельзя ломать.
- **Сундук:** после раскопки сундук открывается ПКМ. Лут обновляется при автоматическом закапывании могил согласно `refill-interval-seconds` (по умолчанию 30 минут).
- **Голограммы:** индивидуальные голограммы прозрачные, восстанавливаются при загрузке чанка и показываются примерно в радиусе 6 блоков при стандартном диапазоне отслеживания сущностей.
- **Призраки кладбища:** одновременно не более 8 Allay; они не подбирают и не дублируют предметы, остаются в границах и бесшумно возрождаются ровно через 10 минут после смерти. При убийстве не отправляется сообщение и выпадает только один кастомный «Призрачный осколок» (без опыта, бонусного лута и ключей). Сущности Cemetery удаляются при отключении плагина и очищаются из загруженных/позже загруженных чанков.
- **Осквернённый Страж:** появляется с шансом `wither-skeleton-chance`; только он может дать ключ ElytrixVault (`guardian-key-drop-chance`) и награды из таблицы стражей.
- **Лут:** `/cemetery loot <graves|ghosts>` открывает 4-страничный редактор. Предметы сохраняются как ItemStack с их метаданными и PDC других плагинов. Существующая пустая таблица не заменяется дефолтной, а запись выполняется атомарно; пустая таблица не подмешивает встроенные предметы.
- **Связь с данжами:** ElytrixDungeons обращается к Cemetery только за фабрикой единого осколка для соответствующих наград. Популяции призраков и их управление остаются независимыми.

## Регион WorldGuard

Создаётся регион `elytrix_cemetery` по `boundary-radius`. PvP и доступ к сундукам разрешены; взрывы криперов, TNT и прочие взрывы запрещены. Строительство внутри кладбища запрещено, кроме администратора с правом `elytrixcemetery.admin`, который крадётся.

## Команды

| Команда | Описание | Доступ |
|---|---|---|
| `/cemetery help` | Список команд | Все игроки |
| `/cemetery info` | Статистика кладбища и его настроенная локация | Все игроки |
| `/cemetery tp` | Телепортация на безопасное место; cooldown 5 минут | Все игроки |
| `/cemetery actionbar` | Переключить общий ActionBar | Все игроки |
| `/cemetery on` / `/cemetery off` | Включить / выключить ActionBar | Все игроки |
| `/cemetery loot <graves\|ghosts>` или `/cemetery edit <graves\|ghosts>` | Редактор таблицы лута | `elytrixcemetery.admin` |
| `/cemetery refill` | Закопать раскопанные могилы | `elytrixcemetery.admin` |
| `/cemetery paste` | Вставить схему или сгенерировать кладбище | `elytrixcemetery.admin` |
| `/cemetery clear` | Удалить зарегистрированные могилы, призраков и блоки генератора | `elytrixcemetery.admin` |
| `/cemetery reload` | Перезагрузить конфигурацию и таблицы лута | `elytrixcemetery.admin` |

## PlaceholderAPI

- `%elytrixcemetery_time%` — время до обновления могил (MM:SS)
- `%elytrixcemetery_active%` — могилы, доступные для раскопки
- `%elytrixcemetery_total%` — общее количество зарегистрированных могил
- `%elytrixcemetery_ghosts%` — живые призраки кладбища
- `%elytrixcemetery_status%` — статус ивента
- `%elytrixcemetery_location%` — название локации
