# Как пустить игроков с 1.21.4 на сервер 1.21.11

## Главное

**Одного ViaVersion мало.** ViaVersion пускает только *новых* клиентов на
*старый* сервер. Чтобы клиент *старше* сервера (1.21.4 на 1.21.11) мог
зайти, нужен аддон **ViaBackwards** — он работает только вместе с
ViaVersion.

| Что нужно | Кто заходит |
| --- | --- |
| ViaVersion | клиент новее сервера |
| ViaVersion + **ViaBackwards** | клиент старше сервера (1.21.4 → 1.21.11) |
| + ViaRewind | ещё и 1.8–1.12 |

## Установка

1. Скачай ViaBackwards **той же линейки**, что и ViaVersion (сейчас 5.12.1):
   - https://github.com/ViaVersion/ViaBackwards/releases/latest
   - файл `ViaBackwards-5.12.1.jar`
2. Проверь, что `plugins/ViaVersion-<версия>.jar` — не старее
   https://github.com/ViaVersion/ViaVersion/releases/latest
   (старый ViaVersion не знает протоколов 1.21.11).
3. Положи `ViaBackwards-*.jar` в `plugins/`, перезапусти сервер.
4. В консоли должно появиться `Enabling ViaBackwards`, а `/viaversion list`
   покажет 1.21.4 у зашедшего игрока.

Без ViaBackwards игрок 1.21.4 получает **«Outdated server!»** — это отказ
на этапе handshake, до плагинов и анимаций дело не доходит.

## Что будет видно на 1.21.4

Анимация «Вихрь» совместима полностью: Breeze (1.20.4+), булава `MACE`
(1.21), стенды/предметы/игрок, звуки — всё есть в 1.21.4. Частицы `GUST`,
`GUST_EMITTER_LARGE`, `WHITE_SMOKE` тоже есть в 1.21.4 (проверено по
`Particle` из Paper 1.21.4).

Для ещё более старых клиентов в аддоне 1.42 есть `compatParticles: true`:
игрокам ниже 1.21.4 новые частицы автоматически уходят как `CLOUD`
(версия определяется через ViaVersion по рефлексии, без зависимости).

Ограничение самого Via: чего нет в 1.21.4 — того не будет.
- Предметы/блоки, добавленные в 1.21.5+ (например, медные из 1.21.9),
  старый клиент увидит заглушкой или пустотой. Если такие есть в
  `prizes.yml` кейсов или в меню BMenu — лучше заменить на старые.
- Новые зачарования/компоненты предметов могут отображаться иначе.
