# ElytrixItem 2.0

Кастомные предметы ElytriX для Paper 1.21.11. Всё, что раньше лежало в
ExecutableItems (броня, мечи, кирки), теперь своё — плюс булава, которой
в ExecutableItems не было.

## Команда

```
/eitems give <ник> <id> [количество]   # выдать предмет (количество по умолчанию 1)
/eitems menu                           # меню всех предметов
/eitems reload
```

`/elytrixitems` — полное имя, `eitems` — короткое.

## Горшочек с опытом

Хранит до **1000** очков опыта. Собирает опыт, пока лежит во второй руке.
`SHIFT + ПКМ` в основной руке выдаёт **250** опыта за клик.

## Остальные предметы

`kirkaraskola` (Кирка Раскола), `collector_sword`, `tyagun`, `infinite_firework`, `experience_pot`,
`anti_pearl`, `explosive_trap`, ауры (`miner_aura`, `fall_protection_aura`,
`crystal_protection_aura`) и книги зачарований (`enchant_byr`,
`enchant_explosive_arrow`, `enchant_sun_shackles`) — как раньше.

## Магазин

`/shop` в BMenu выдаёт новые предметы командой `eitems give` и **не
закрывает меню** после покупки. Булава и кирка слаймера — в разделе
«Уникальные предметы» (Кирка Раскола); булава — в «Амуниции».

## Сборка

Maven не нужен: `bash tools/build.sh <java-runtime> <ecj.jar>` — компилирует
`stubs/` и `src/main/java` через ECJ и собирает jar упаковщиком
`tools/mkjar.py`.
