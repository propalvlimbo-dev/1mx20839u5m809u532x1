# ElytrixAddonSphere — новая анимация (Вихрь)

## Что сейчас (нужно подтвердить)

Судя по описанию: предметы вылетают сверху и собираются в круг (сфера/карусель),
крутятся вокруг блока кейса. Исходников в репозитории пока нет — залей папку
аддона сюда, тогда перепишу сам код.

## Что делаем

В центр кейса ставится **Вихрь (Breeze)** из 1.21 через **VirtualEntityApi**
(та же библиотека автора BCases/BMenu — `By1337/VirtualEntityApi`).
Это пакетный моб: не настоящий, не лагает, не бьётся, не спавнится в мире.

### Таймлайн

| Фаза | Время | Что происходит |
|---|---|---|
| 0. Сбор | 0–1.0 с | предметы вылетают сверху и встают в круг радиусом 1.2, Вихрь появляется в центре |
| 1. Круг | 1.0–3.0 с | круг крутится медленно (≈90°/с), Вихрь медленно вращается на месте |
| 2. Подъём | 3.0–4.5 с | Вихрь поднимается на +2.0 блока, круг поднимается вместе с ним, радиус 1.2 → 1.6 |
| 3. Разгон | 4.5–7.0 с | скорость растёт линейно ×1 → ×4, частицы `GUST`/`CLOUD`, звук нарастает |
| 4. Взрыв | 7.0 с | предметы разлетаются в стороны и исчезают, Вихрь гаснет |
| 5. Итог | 7.0+ | возле центра остаётся только выпавший лут |

### Реализация центра

```java
VirtualTracker tracker = new VirtualTracker(plugin, caseLocation); // обёртка над PlayerTracker

VirtualBreeze breeze = VirtualBreeze.create();
breeze.setPos(new Vec3d(caseLocation.clone().add(0, 0.3, 0)));
breeze.setNoAi(true);
breeze.setSilent(true);
tracker.add(breeze);            // tick 1 раз в тик, только для игроков в радиусе
```

* подъём — `breeze.setPos(...)` с интерполяцией по тикам (клиент сам сглаживает);
* вращение — `breeze.setYaw(yaw)` (0–360, растёт каждый тик);
* исчезновение — `tracker.remove(breeze)` (шлёт пакет удаления только зрителям).

### Что нужно на сервере

* `VirtualEntityApi-1.4.3.jar` + `BLib` (зависимость) в `plugins/`;
* в аддоне зависимость `compileOnly 'dev.by1337.virtualentity.api:VirtualEntityApi-api:1.4.3'`;
* Java 21+, Paper 1.21.11.
