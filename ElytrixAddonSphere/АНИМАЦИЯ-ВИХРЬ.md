# ElytrixAddonSphere 1.26 — что изменилось

## 1. Крутилось прерывисто — исправлено

Причина была в архитектуре: кольцо двигал поток анимации (`sleepTicks` +
`for`-цикл), а пакеты позиций уходят из тикера сервера. Поток и тикер
рассинхронизировались — отсюда рывки, особенно заметные на быстром
вращении.

Теперь всё движение считает **один тик-таск** (`AsyncTask.create(drive).delay(1).timer()`),
ровно 20 раз в секунду:

* кольцо призов — `ringAngle += curSpeed` каждый тик;
* Вихрь — своё вращение `breezeYaw += breezeSpin`;
* приз-победитель — своя орбита.

Поток анимации только переключает фазы. Скорость, радиус и высота
подтягиваются к целевым значениям плавно (`lerp`), поэтому нет рывков
на старте и при переходах.

## 2. Взлёт и удар

| Что было | Что стало |
|---|---|
| Вихрь «подпрыгивал» и резко падал | быстрый, но плавный взлёт (ease-out, `breezeUpTicks: 6` = 0.3 с), 3 тика зависания наверху и удар вниз за `breezeDownTicks: 4` (0.2 с) с ускорением |

В момент удара: звук `ENTITY_GENERIC_EXPLODE`, вспышка частиц, остальные
призы разлетаются и исчезают, и ровно в этот момент приз выходит на орбиту.

## 3. Приз на орбите 3–5 секунд

`winnerOrbitTicks: 80` = **4 секунды**. Приз плавно входит на орбиту
(радиус и высота подтягиваются от точки удара), разгоняется от 0 до
`winnerOrbitSpeed: 8`°/тик — круг примерно за 3.6 с, с лёгким покачиванием
по высоте (`sin`).

## 4. Плавность и пакеты

* предметы падают на орбиту **каждый со своей точки** (ease-out, каскад);
* `moveTo()` отправляет позицию только если она реально изменилась
  (порог 0.005 блока) — меньше пакетов, нет дрожания;
* частицы: след по кольцу 1 предмет из 3, Вихрь — раз в 3 тика.

Тайминг (~6.4 с): падение призов 0.5 с → круг 5 с → взлёт 0.3 с →
удар 0.2 с → орбита приза 4 с.

## 5. Настройки

```yaml
settings:
  breezeSpin: 14.0         # вращение Вихря, °/тик
  breezeRise: 2.6          # на сколько взлетает
  winnerOrbitRadius: 1.05  # радиус орбиты приза
  winnerOrbitSpeed: 8.0    # °/тик, круг ≈ 3.6 с
  timings:
    breezeUpTicks: 6       # быстрый взлёт
    breezeDownTicks: 4     # резкий удар
    winnerOrbitTicks: 80   # 4 секунды орбиты приза
    impactSound: "ENTITY_GENERIC_EXPLODE"
```

Чтобы получить файл с новыми комментариями — удали старый
`plugins/BCases/addons/sphereAnimation.yml`, перезапусти сервер:
аддон скопирует свежий.

## 6. Сборка

`downloads/ElytrixAnimAddon-1.26.jar` (≈17.4 КБ), собран ECJ 3.38 под
Java 17 против API BCases 1.2 / VirtualEntityApi 1.4.2.
