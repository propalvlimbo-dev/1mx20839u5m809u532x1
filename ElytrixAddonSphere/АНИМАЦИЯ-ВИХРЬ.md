# ElytrixAddonSphere 1.28 — что изменилось

## 1. Вращение Вихря больше не прерывается

Раньше визуал двигал отдельный таск (тикер BCases), а пакеты поворота
отправляет VirtualEntityApi в своём тике. Два разных таймера → иногда два
обновления за один пакет, иногда ноль → рывки, особенно на быстром вращении.

Теперь драйвер висит **на тике самой сущности** (`addTickTask`): он
вызывается ровно один раз перед отправкой пакетов. Один тик — один поворот,
без пропусков и двойных шагов. Если версия VirtualEntityApi старая и метода
нет — аддон автоматически возвращается к обычному таску.

Плюс скорость вращения снижена до `breezeSpin: 6` (120°/с): голова Вихря
всё равно шлётся отдельным пакетом без интерполяции, на больших скоростях
она «телепортируется». Быстроту компенсируют искры и кольцо (9°/тик).

## 2. Искры, которые видны даже с выключенными частицами

Частицы Minecraft клиент скрывает при настройке «Минимум/Выкл». Поэтому
добавлены **искры-предметы**: пакетные `VirtualItem` с `GLOWSTONE_DUST`.

* два кольца по `sparkCount: 8` искр, крутятся в разные стороны
  (`sparkSpeed: 18`°/тик — оборот за секунду);
* радиус `sparkRadius: 1.15` и `0.62×` для второго кольца;
* при подлёте искры сжимаются к Вихрю и раскручиваются в 2.2×,
  после удара — обратно.

Их видно всегда, на любых настройках частиц.

## 3. Призы качаются сильнее

`bobAmplitude: 0.45` блока (было 0.16), `bobSpeed: 0.13` — призы заметно
ходят вверх-вниз, у каждого своя фаза. Имя приза качается вместе с ним.

## 4. Эпичный подлёт и удар

* подлёт: звук, винтовая колонна `END_ROD`, сжатие и раскрутка искр,
  в конце — аметистовый «дзынь» и вспышка;
* удар: взрыв погромче, `SWEEP_ATTACK`, 70 частиц, 14 искр-предметов
  разлетаются по кругу (видно и без частиц) и гаснут за 12 тиков.

## 5. Булава бьёт Вихря

Новый блок сценария `maceStrike()`:

1. Вихрь подлетает (`breezeRise: 1.6`) и замирает на `breezeHoverTicks: 6`;
2. сверху с высоты `maceHeight: 7` падает `MACE` за `maceFallTicks: 8`
   с ускорением (ease-in), за ним тянется след `END_ROD`;
3. удар: звук взрыва + аметист, `SWEEP_ATTACK`, 45 частиц;
4. от удара Вихрь резко падает за `breezeDownTicks: 4`, в момент
   приземления — большой взрыв, разлёт искр и выпадение приза.

## 6. Настройки (новые ключи)

```yaml
settings:
  rotationSpeed: 9.0
  bobAmplitude: 0.45      # покачивание призов, блоки
  bobSpeed: 0.13          # радиан за тик
  dropHeight: 5.0
  breezeSpin: 6.0         # плавное вращение
  breezeRise: 1.6
  particleVector: "END_ROD"

  sparks: true            # искры-предметы (видны без частиц)
  sparkCount: 8
  sparkRadius: 1.15
  sparkSpeed: 18.0
  sparkHeight: 0.9
  sparkMaterial: "GLOWSTONE_DUST"
  shockMaterial: "GLOWSTONE_DUST"

  mace: true
  maceMaterial: "MACE"
  maceHeight: 7.0

  winnerOrbitRadius: 1.05
  winnerOrbitSpeed: 8.0

  timings:
    breezeUpTicks: 8
    breezeHoverTicks: 6
    maceFallTicks: 8
    breezeDownTicks: 4
    winnerOrbitTicks: 80
```

Старый `sphereAnimation.yml` содержит прежние значения (`breezeSpin: 9`,
`breezeRise: 1.3`, `bobAmplitude: 0.16`) — они перебьют новые. Удали файл
и перезапусти сервер, аддон скопирует свежий.

## 7. Сборка

`downloads/ElytrixAnimAddon-1.28.jar` (≈22 КБ), собран ECJ 3.38 под Java 17
против API BCases 1.2 / VirtualEntityApi 1.4.2.
