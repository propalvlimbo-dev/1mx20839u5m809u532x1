# ElytrixAddonSphere 1.39 — что изменилось

## 0. Что нового в 1.39

- **Вихрь поднимается выше:** `breezeRise: 3.2` (было 2.2), 16 тиков.
- **Удар обрывает подъём:** булава стартует так, чтобы врезаться ровно в
  верхней точке — Вихрь больше не зависает и не ждёт удара.
- **Эффектов от удара ещё меньше:** `GUST_EMITTER_LARGE`(1) +
  `SWEEP_ATTACK`(1), два звука. На приземлении одна частица и один звук,
  «волна» и лишние вспышки убраны.

## Ранее (1.38)

## 0. Что нового в 1.38

- **Удар — минимум частиц:** `GUST_EMITTER_LARGE`(1) + `GUST`(1) +
  `WHITE_SMOKE`(1) + `SWEEP_ATTACK`(1). При приземлении столько же,
  «волна» урезана с 7×8 до 4×4.
- **Вихрь поднимается выше:** `breezeRise: 2.2` (было 1.2), 12 тиков.

## 1. Взгляд Вихря больше не «телепортируется»

- `breezeSpin: 3.5` (было 6.0) — 70°/с, как в конце анимации, где вращение
  тебе нравилось.
- Скорость раскрутки набирается с нуля очень мягко, и больше нет ускорений
  в 2.8× на ударе — из-за них голова дёргалась рывками.

## 2. Подъём чуть-чуть → замер → резкий удар

```yaml
settings:
  breezeRise: 1.2          # было 2.4 — теперь «чуть-чуть»
timings:
  breezeUpTicks: 10        # 0.5 с, сразу бодрый старт (ease-out)
  breezeHoverTicks: 4      # короткое замирание наверху
  maceFallTicks: 6         # булава врезается резко, 0.3 с
```

Сцена: Вихрь приподнялся → замер → сверху врезается **rooyzee** с булавой →
Вихрь дрожит и падает, остальные призы осыпаются.

## 3. Призы снова строго по кругу + покачивание

Позиция каждого приза теперь считается **от его индекса**:
`угол = 2π·i / count`, радиус берётся из `radius` напрямую. Массив слотов и
плавное «сжатие» радиуса больше не участвуют — призы физически не могут
собраться в одну точку.

```yaml
settings:
  radius: 2.5
  bobAmplitude: 0.12   # чуть-чуть вверх-вниз во время вращения
  bobSpeed: 0.13       # у каждого приза своя фаза
```

## 4. Призы теперь видны

Стенд приза был `marker: true` — такие стенды **не рисуют предмет**.
Теперь это невидимый обычный стенд (`invisible`, `marker: false`), предмет
висит на голове.

## 5. Частицы

- Удар булавы: `GUST_EMITTER_LARGE` + `GUST`(3) + `WHITE_SMOKE`(4) +
  `SWEEP_ATTACK`(1) + пыль(4) — немного, по делу.
- Снежинкоподобных `CRIT`/`FIREWORK` в аддоне нет вообще.
- Атмосферные частицы выключены (`particlesAmbient: false`).

## 6. Конфиг обновляется сам

В `sphereAnimation.yml` появился `configVersion: "1.39"`. При запуске аддон
сравнивает его со своей версией: если файл старый — переименовывает его в
`sphereAnimation.old.yml` и создаёт свежий. Больше не нужно удалять вручную.

## 7. Сборка

`downloads/ElytrixAnimAddon-1.39.jar` (≈25 КБ) — ECJ 3.38, Java 17,
BCases 1.2 / VirtualEntityApi 1.4.2.

Конфиг: `plugins/BCases/animations/sphere/sphereAnimation.yml` — после замены
jar удали его при выключенном сервере, аддон создаст свежий.
