# ElytrixAddonSphere 1.27 — что изменилось

## 1. Призы снова летают по кругу (были в куче)

В 1.26 позиция приза считалась как `toRadians(slot)`, хотя слоты уже хранятся
в радианах (`2π·i/count`). Кольцо сжималось в дугу ~6° — все 10 призов
висели в одном месте.

Теперь `ringPos` = `slot + toRadians(ringAngle)` — полный круг, как раньше.
Призы появляются каждый **над своим местом** в кольце (а не из одной точки
над кейсом) и плавно опускаются на орбиту.

Плюс новое: призы чуть-чуть покачиваются вверх-вниз во время вращения,
у каждого своя фаза (`bobAmplitude: 0.16`, `bobSpeed: 0.10`).

## 2. Взгляд Вихря больше не «телепортируется»

Причина: каждый тик сервер отправляет поворот головы отдельным пакетом,
и на 14°/тик (а в ударе — до 40°/тик) голова прыгала. В конце анимации
скорость была 7°/тик — поэтому там «нормально».

Сделано:

* старт с нулевой скорости и плавный разгон (`breezeSpinSpeed` тянется
  к цели по 15% за тик) — первые кадры почти без вращения;
* скорость вращения ограничена: `breezeSpin: 9` (0.5 оборота в секунду),
  в ударе максимум 12°/тик вместо 40;
* после удара — спокойные 0.6–0.8× от базовой.

## 3. Подлёт → замирание → удар

| Параметр | Было в 1.26 | Стало в 1.27 |
|---|---|---|
| `breezeRise` | 2.6 блока | **1.3** — «чуть-чуть» вверх |
| `breezeHoverTicks` | 3 (жёстко в коде) | **8** — заметно замирает наверху |
| `breezeDownTicks` | 4 | 4 (как и было — резкий удар) |

Взлёт по-прежнему ease-out (быстрый старт, мягкое торможение), удар —
ease-in (ускорение вниз), в момент удара выпадает приз.

## 4. Орбита приза

`winnerOrbitTicks: 80` = 4 секунды, `winnerOrbitSpeed: 8`°/тик,
радиус плавно подтягивается от точки удара к `winnerOrbitRadius: 1.05`.

## 5. Настройки

```yaml
settings:
  breezeSpin: 9.0          # °/тик, плавный разгон от 0
  breezeRise: 1.3          # на сколько подлетает
  dropHeight: 5.0          # с какой высоты опускаются призы
  bobAmplitude: 0.16       # покачивание призов вверх-вниз
  bobSpeed: 0.10           # радиан за тик
  winnerOrbitRadius: 1.05
  winnerOrbitSpeed: 8.0
  timings:
    breezeUpTicks: 6       # взлёт 0.3 с
    breezeHoverTicks: 8    # замирание наверху
    breezeDownTicks: 4     # удар 0.2 с
    winnerOrbitTicks: 80   # 4 с орбиты приза
    impactSound: "ENTITY_GENERIC_EXPLODE"
```

Старый `sphereAnimation.yml` содержит прежние значения (`breezeSpin: 14`,
`breezeRise: 2.6`) — они перебьют новые. Удали файл и перезапусти сервер,
аддон скопирует свежий.

## 6. `/case` и выдача кейса

Алиас `case` у меню-рулетки закомментирован (`BMenu/config.yml`), рулетка
осталась на `/wheel`. Кейс выдаётся так:

```
/case give <ник> <id> [количество] [срок]   # например: /case give Rooyzee default 5 10y
/case set default                          # сделать кейсом блок, на который смотришь
/case play elytrix:sphere default          # проиграть анимацию
```

## 7. Сборка

`downloads/ElytrixAnimAddon-1.27.jar` (≈18 КБ), собран ECJ 3.38 под Java 17
против API BCases 1.2 / VirtualEntityApi 1.4.2.
