# ElytrixAddonSphere 1.32 — что изменилось

## 1. Снежный «спам» — это сам моб Breeze, а не аддон

Все белые снежинки в кадре — встроенный эффект моба **Breeze**: клиент
рисует их вокруг него постоянно. Плагином это не отключается (в конфиге
частиц Minecraft их тоже нет — только «Частицы: Минимум», который гасит
вообще всё).

Поэтому добавлен режим:

```yaml
settings:
  breezeMode: "VORTEX"    # по умолчанию — без моба
  # "BREEZE" — вернуть моба (у него будет его снежный аура)
```

## 2. Вихрь теперь из частиц

В режиме `VORTEX` моба нет вообще — вихрь рисует спираль частиц:

```yaml
settings:
  vortexParticle: "WHITE_SMOKE"  # 1.21.4; можно CLOUD / END_ROD / SNOWFLAKE
  vortexEvery: 3                 # одна частица раз в 3 тика (≈7 в секунду)
  vortexRadius: 0.55             # радиус спирали
```

Частица крутится по спирали и плавно гуляет по высоте — читается как
вихрь, но частиц ровно столько, сколько в конфиге. Подлёт, удар булавой
и падение работают как раньше: спираль поднимается и падает.

Плюс всё ещё есть `ambientParticle`/`ambientEvery` — одна лёгкая частица
раз в 14 тиков для атмосферы.

## 3. Остальное без изменений

Сценарий: кольцо призов → подлёт → замирание → игрок **rooyzee** со скином
и булавой бьёт Вихря → Вихрь сразу падает, остальные призы резко падают
вниз и исчезают → приземление, взрыв и орбита приза 4 секунды.

## 3. Сценарий (без изменений с 1.30)

1. Призы падают на кольцо каждый со своего места, кольцо крутится.
2. Вихрь подлетает на `breezeRise: 1.6`, замирает `breezeHoverTicks: 6`.
3. Сверху прыгает виртуальный игрок **rooyzee** со скином и `MACE`,
   бьёт Вихря (`SWING_MAIN_ARM`), звук + вспышка.
4. В тот же тик Вихрь падает (`breezeDownTicks: 4`), а все призы кроме
   выигрыша резко падают вниз и исчезают.
5. В момент приземления — взрыв, расходящееся кольцо частиц, выпадает приз
   и 4 секунды летает по орбите (`winnerOrbitTicks: 80`,
   `winnerOrbitSpeed: 8`, радиус `winnerOrbitRadius: 1.05`).

## 4. Настройки

```yaml
settings:
  radius: 2.5
  itemCount: 10
  rotationSpeed: 9.0
  height: 0.35
  nameOffset: 1.15
  bobAmplitude: 0.0          # покачивание выключено
  dropHeight: 5.0
  particleVector: "FIREWORK" # видно и при «Частицы: Меньше»
  particleItems: "REDSTONE"
  ambientParticle: "WHITE_SMOKE"
  ambientEvery: 14
  breezeSpin: 6.0
  breezeRise: 1.6
  breezeHeight: -0.45
  breezeParticle: "CLOUD"
  mace: true
  maceMaterial: "MACE"
  maceName: "rooyzee"
  maceHeight: 7.0
  winnerOrbitRadius: 1.05
  winnerOrbitSpeed: 8.0
  timings:
    ascentSteps: 8
    ascentGap: 2
    orbitTicks: 80
    breezeUpTicks: 8
    breezeHoverTicks: 6
    maceFallTicks: 8
    breezeDownTicks: 4
    winnerOrbitTicks: 80
    breezeStayTicks: 12
```

Старый `sphereAnimation.yml` перебьёт новые значения — удали его
(`plugins/BCases/addons/sphereAnimation.yml`) и перезапусти сервер,
аддон скопирует свежий.

## 5. Сборка

`downloads/ElytrixAnimAddon-1.32.jar` (≈23 КБ), собран ECJ 3.38 под Java 17
против API BCases 1.2 / VirtualEntityApi 1.4.2.
