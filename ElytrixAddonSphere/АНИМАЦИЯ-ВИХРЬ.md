# ElytrixAddonSphere 1.29 — что изменилось

## 1. Только частицы, никаких предметов-искр

Убраны пакетные предметы (glowstone dust), которые изображали искры.
Вся «магия» теперь на частицах:

* винтовая дорожка `END_ROD` вокруг Вихря — каждые 2 тика;
* след кольца `particleVector: END_ROD` (можно `ELECTRIC_SPARK` или `REDSTONE`);
* подлёт: колонна `END_ROD`, вспышка, аметистовый звук;
* удар: `REDSTONE` (цвет из настроек) + `CLOUD`, `SWEEP_ATTACK`, `CRIT`;
* после приземления: расходящееся кольцо частиц радиусом до 3.5 блоков;
* за игроком с булавой тянется след `END_ROD`.

## 2. Призы больше не качаются

Покачивание вверх-вниз убрано: `bobAmplitude: 0`. Предметы просто ровно
летят по кругу. Если когда-нибудь захочется вернуть — поставь, например,
`0.2`.

## 3. Булава: теперь это виртуальный игрок

Вместо парящего предмета сверху прыгает **виртуальный игрок** (`VirtualPlayer`)
с булавой в руке:

1. появляется на высоте `maceHeight: 7` над Вихрем;
2. падает вниз с ускорением (`maceFallTicks: 8`), за ним след частиц;
3. приземляется прямо в Вихря и **замахивается рукой**
   (`SWING_MAIN_ARM`), звук взрыва + аметист, вспышка частиц;
4. стоит ещё 5 тиков («как будто бьёт») и исчезает;
5. от удара Вихрь резко падает и в момент приземления выпадает приз.

Настройки:

```yaml
settings:
  mace: true
  maceMaterial: "MACE"   # предмет в руке
  maceName: "Mace"       # ник виртуального игрока
  maceHeight: 7.0        # с какой высоты прыгает
```

## 4. Что ещё осталось с прошлых версий

* вращение привязано к тику сущности — один поворот на один пакет;
* `breezeSpin: 6` — плавно, без «телепортации» головы;
* подлёт `breezeRise: 1.6` → замирание `breezeHoverTicks: 6` → игрок
  с булавой → падение `breezeDownTicks: 4`;
* приз летает по орбите 4 секунды (`winnerOrbitTicks: 80`).

## 5. Настройки (актуальные)

```yaml
settings:
  radius: 2.5
  itemCount: 10
  rotationSpeed: 9.0
  height: 0.35
  nameOffset: 1.15
  bobAmplitude: 0.0        # покачивание выключено
  dropHeight: 5.0
  particleVector: "END_ROD"
  particleItems: "REDSTONE"
  breezeSpin: 6.0
  breezeRise: 1.6
  breezeHeight: -0.45
  breezeParticle: "CLOUD"
  mace: true
  maceMaterial: "MACE"
  maceName: "Mace"
  maceHeight: 7.0
  winnerOrbitRadius: 1.05
  winnerOrbitSpeed: 8.0
  timings:
    ascentSteps: 8
    ascentGap: 2
    orbitTicks: 80
    breezeUpTicks: 8
    breezeHoverTicks: 6
    maceFallTicks: 8
    breezeDownTicks: 4
    winnerOrbitTicks: 80
    breezeStayTicks: 12
```

Старый `sphereAnimation.yml` содержит прежние значения (`bobAmplitude: 0.45`,
ключи `spark*`) — они перебьют новые. Удали файл и перезапусти сервер,
аддон скопирует свежий.

## 6. Сборка

`downloads/ElytrixAnimAddon-1.29.jar` (≈21 КБ), собран ECJ 3.38 под Java 17
против API BCases 1.2 / VirtualEntityApi 1.4.2.
