# ElytrixAddonSphere 1.34 — проверка частиц

## 1. Аддон не рисует НИ ОДНОЙ частицы

Добавлен общий выключатель:

```yaml
settings:
  particles: false    # false = ни одна частица аддона не рисуется
```

Он стоит первым в `fx()` — все эффекты (вихрь, следы, взрывы, атмосфера)
выходят сразу, не отправляя ни одного пакета. Сейчас по умолчанию `false`,
чтобы проверить источник снежинок.

Проверка: перезапустить сервер и запустить кейс.
* снежинки остались → их спамит не аддон (погода или другой плагин);
* снежинки пропали → значит это были наши эффекты, тогда включи
  `particles: true` и дальше будем точечно гасить нужное.
