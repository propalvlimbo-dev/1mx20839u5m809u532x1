# ElytrixAddonSphere 1.33 — что изменилось

## 1. Вихрь вернулся

Снежинки в кадре остались даже после удаления моба — значит они **не от
аддона**. Поэтому режим по умолчанию снова `breezeMode: "BREEZE"` —
видимый Вихрь на месте. Режим `VORTEX` (без моба, только спираль частиц)
остался как альтернатива.

## 2. Где лежит конфиг анимации

```
plugins/BCases/animations/sphere/sphereAnimation.yml
```

Именно этот файл читает аддон: удалить мало — после удаления нужно
**перезапустить сервер**, аддон заново скопирует свежий файл из jar
(проверка `if (targetFile.exists()) return;` — файл создаётся только при
включении аддона).

## 3. Откуда снежинки

Пока моб был убран, частицы остались — значит их спамит что-то другое.
Проверка по порядку:

1. **Погода.** В снежном биоме идёт снег частицами `snowflake` по всей
   округе. Проверь: `/weather clear`. Если частицы пропали — это снег,
   лечится `/gamerule doWeatherCycle false`.
2. **Другой плагин.** Поиск по конфигам (Windows, cmd):

   ```
   findstr /S /I /C:"SNOWFLAKE" C:\Users\admin\Desktop\1.21.11\Grief\plugins\*.yml
   ```

   Найденный файл — источник.
3. Если ничего не нашлось — скинь `plugins/BCases/config.yml` и список
   плагинов, разберёмся.

Аддон сам рисует только `FIREWORK`, `EXPLOSION`, `WHITE_SMOKE` и
`REDSTONE` в радиусе ≤ 3.5 блоков от кейса — то, что на скриншоте летает
по всему небу, это не он.

## 4. Сценарий
 (без изменений с 1.30)

1. Призы падают на кольцо каждый со своего места, кольцо крутится.
2. Вихрь подлетает на `breezeRise: 1.6`, замирает `breezeHoverTicks: 6`.
3. Сверху прыгает виртуальный игрок **rooyzee** со скином и `MACE`,
   бьёт Вихря (`SWING_MAIN_ARM`), звук + вспышка.
4. В тот же тик Вихрь падает (`breezeDownTicks: 4`), а все призы кроме
   выигрыша резко падают вниз и исчезают.
5. В момент приземления — взрыв, расходящееся кольцо частиц, выпадает приз
   и 4 секунды летает по орбите (`winnerOrbitTicks: 80`,
   `winnerOrbitSpeed: 8`, радиус `winnerOrbitRadius: 1.05`).

## 4. Настройки

```yaml
settings:
  radius: 2.5
  itemCount: 10
  rotationSpeed: 9.0
  height: 0.35
  nameOffset: 1.15
  bobAmplitude: 0.0          # покачивание выключено
  dropHeight: 5.0
  particleVector: "FIREWORK" # видно и при «Частицы: Меньше»
  particleItems: "REDSTONE"
  ambientParticle: "WHITE_SMOKE"
  ambientEvery: 14
  breezeSpin: 6.0
  breezeRise: 1.6
  breezeHeight: -0.45
  breezeParticle: "CLOUD"
  mace: true
  maceMaterial: "MACE"
  maceName: "rooyzee"
  maceHeight: 7.0
  winnerOrbitRadius: 1.05
  winnerOrbitSpeed: 8.0
  timings:
    ascentSteps: 8
    ascentGap: 2
    orbitTicks: 80
    breezeUpTicks: 8
    breezeHoverTicks: 6
    maceFallTicks: 8
    breezeDownTicks: 4
    winnerOrbitTicks: 80
    breezeStayTicks: 12
```

Старый `sphereAnimation.yml` перебьёт новые значения — удали его
(`plugins/BCases/addons/sphereAnimation.yml`) и перезапусти сервер,
аддон скопирует свежий.

## 5. Сборка

`downloads/ElytrixAnimAddon-1.33.jar` (≈23 КБ), собран ECJ 3.38 под Java 17
против API BCases 1.2 / VirtualEntityApi 1.4.2.
