# ElytrixAddonSphere 1.25 — что изменилось

## 1. `/case` открывал рулетку — исправлено

В `BMenu/config.yml` меню `elytrix:cases_wheel` (рулетка) было привязано
к командам `/wheel` **и** `/case`. Из-за этого `/case` перебивал команду
BCases (`/bcases`, алиас `case`).

Алиас `case` у меню закомментирован — рулетка осталась на `/wheel`.

## 2. Как выдать себе кейс

```
/case give <ник> <id> [количество] [срок]
```

* `id` — набор призов из `plugins/BCases/prizes.yml` (секция `prizes:`),
  например `default`;
* срок можно не писать — по умолчанию 10 лет;
* пример: `/case give Rooyzee default 5 10y`.

Другие полезные:

```
/case set default                 # сделать кейсом блок, на который смотришь
/case play elytrix:sphere default # проиграть анимацию на этом кейсе
/case take <ник> <id> 1           # забрать ключ
/case clear <ник>                 # убрать все ключи
/case reload
```

Права: `bcases.admin`, `bcases.admin.give`, `bcases.admin.play` и т. д.

## 3. Анимация

| Что просили | Что сделано |
|---|---|
| Вихрь плавнее и быстрее крутится | `breezeSpin: 6 → 14` (≈0.8 оборота в секунду), вращение линейное, с плавным разгоном от 0.7× до 1.15× в фазе круга |
| Вихрь сначала резко вверх, потом вниз | новая фаза `breezeUpDown`: взлёт `breezeUpTicks: 8` (0.4 с, ease-out — резкий старт, мягкое торможение), падение `breezeDownTicks: 22` (1.1 с, smoothstep) |
| Награда не в Вихре, а летает вокруг | приз выходит на орбиту `winnerOrbitRadius: 1.05` со скоростью `winnerOrbitSpeed: 3.5`°/тик, с плавным входом в круг и лёгким покачиванием по высоте |
| Плавно и без лагов | позиции сущностей отправляются только при реальном изменении (`moveTo`, порог 0.005 блока) — меньше пакетов; частицы реже (1 на предмет раз в 3 тика, Вихрь — раз в 2–3 тика) |

Тайминг анимации (~7.5 с): сбор 0.5 с → круг 5 с → взлёт 0.4 с → падение 1.1 с
→ разгон/сжатие 2 с → вылет остальных + орбита приза 2.25 с.

## 4. Настройки (новые ключи)

```yaml
settings:
  breezeSpin: 14.0        # быстрее и плавнее
  breezeRise: 2.6
  winnerOrbitRadius: 1.05 # 0 = приз висит на месте
  winnerOrbitSpeed: 3.5
  timings:
    breezeUpTicks: 8      # резкий взлёт
    breezeDownTicks: 22   # плавное падение
```

Старый `sphereAnimation.yml` содержит `riseTicks` — он всё ещё читается как
`breezeUpTicks`. Чтобы получить файл с новыми комментариями — удали его
и перезапусти сервер.
