# ElytrixAddonSphere 1.36 — что изменилось

## 1. Частицы снежинок убраны

Из эффектов удара убраны `CRIT` и `FIREWORK` — именно они выглядели как
снежинки. Вместо них **частицы булавы**, как в ванильном mace smash:

```yaml
settings:
  maceParticle: "GUST_EMITTER_LARGE"  # большой порыв ветра (1.21+)
  gustParticle: "GUST"                # порывы
  smokeParticle: "WHITE_SMOKE"        # белый дым (1.21.4)
```

Используются: `GUST_EMITTER_LARGE` (1 шт в точке удара), `GUST` (6–8),
`WHITE_SMOKE` (8–10), `SWEEP_ATTACK` (3 — взмах), пыль `REDSTONE`.
Если сервер не знает частицу — тихо берётся `CLOUD`.

То же на приземлении: `GUST_EMITTER_LARGE` + `GUST` + `WHITE_SMOKE`,
а «волна» по кругу теперь из `GUST`, а не из `FIREWORK`.

Заодно `particleVector` по умолчанию `SMOKE` (след кольца), чтобы при
включении атмосферы снежинки не вернулись.

## 2. Вихрь поднимается дольше и выше

```yaml
settings:
  breezeRise: 2.4        # было 1.6
  timings:
    breezeUpTicks: 20    # было 14 (1 секунда, smoothstep)
```

## 3. Группы частиц

```yaml
settings:
  particles: true
  particlesAmbient: false   # спираль вихря, следы, дым — выкл
  particlesImpact: true     # удар булавы, приземление, разлёт — вкл
```

## 4. Сценарий

Кольцо призов → плавный подъём (1 с, 2.4 блока) → замирание → игрок
**rooyzee** со скином и булавой падает с 12 блоков → удар: порыв ветра,
`SWEEP_ATTACK`, звук урона, Вихрь дрожит 8 тиков и падает → остальные призы
резко падают и исчезают → приземление (порыв + дым) и орбита приза 4 с.

## 5. Сборка

`downloads/ElytrixAnimAddon-1.36.jar` (≈25 КБ), собран ECJ 3.38 под Java 17
против API BCases 1.2 / VirtualEntityApi 1.4.2.

Конфиг: `plugins/BCases/animations/sphere/sphereAnimation.yml` — после
замены jar удали его при выключенном сервере, аддон создаст свежий.
