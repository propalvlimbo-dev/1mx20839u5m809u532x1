# ElytrixAddonSphere → анимация с Вихрем

Аддон анимации кейса для BCases (`provider: elytrix:sphere`).

## Что было

Предметы вылетали сверху, собирались в круг и крутились вокруг блока кейса,
в конце победитель поднимался наверх с салютом.

## Что стало

В центр кейса ставится **Вихрь (Breeze)** из 1.21 через **VirtualEntityApi**
(та же библиотека, что у BCases/BMenu — `By1337/VirtualEntityApi`).
Моб пакетный: не лагает, не бьётся, не зависит от чанков, не спавнится по-настоящему.

### Таймлайн

| Фаза | Тики (по умолч.) | Что происходит |
|---|---|---|
| Сбор | ~26 | предметы каскадом падают сверху и встают в круг вокруг Вихря |
| Круг | 100 | Вихрь медленно вращается вокруг оси (`breezeSpin`), круг крутится |
| Подъём | 30 | Вихрь поднимается на `breezeRise` (2.2 блока), круг летит вместе с ним |
| Разгон | 40 | вращение ускоряется ×3, радиус сжимается вдвое, Вихрь крутится быстрее |
| Взрыв | ~45 | остальные предметы разлетаются в стороны и исчезают, салют |
| Итог | 10 | возле Вихря остаётся только выпавший приз, Вихрь гаснет |

## Настройки (`plugins/BCases/animations/sphere/sphereAnimation.yml`)

```yaml
settings:
  breeze: true            # выключить — анимация работает как раньше
  breezeSpin: 6.0         # градусов за тик вокруг своей оси
  breezeRise: 2.2         # на сколько блоков поднимается
  breezeHeight: -0.45     # смещение от центра кейса (стоит на блоке)
  breezeParticle: "CLOUD"

  timings:
    riseTicks: 30         # длительность подъёма
    breezeStayTicks: 10   # сколько крутится после взрыва
```

Файл сохраняется один раз при первом запуске. Если он уже есть — новые ключи
подхватятся автоматически (у всех есть значения по умолчанию), либо удали файл
и он создастся заново.

## Требования

* сервер **Paper 1.21.11** (Breeze есть с 1.20.4);
* плагин **VirtualEntityApi** (+ зависимость **BLib**) в `plugins/`;
* в BCases должна быть подключена анимация `elytrix:sphere`.

Если VirtualEntityApi не установлен — аддон не падает: Вихря просто не будет,
остальная анимация работает.

## Сборка

Уже собран: **`downloads/ElytrixAnimAddon-1.24.jar`** (17 КБ) →
в папку аддонов BCases → `/bcases reload`.

Пересобрать самому:

```
mvn clean package
```

Готовый jar: `target/ElytrixAnimAddon.jar`.

В песочнице Maven недоступен (нет доступа к maven-репозиториям), поэтому jar
собран Eclipse-компилятором (ECJ 3.38, `-17`) против API-заглушек, снятых
с исходников **BCases 1.2** и **VirtualEntityApi** — сигнатуры совпадают,
байткод обычный (class version 61). Если сервер ругнётся на
`NoSuchMethodError` — пересобери через `mvn clean package` у себя.

## Конфиг без Codec

Парсинг `sphereAnimation.yml` переведён с DFU-кодеков на `CashedYamlContext`
(ключи читаются по путям `settings.*`). Причина: у `RecordCodecBuilder`
лимит 16 полей, а с настройками Вихря их стало 17. Все ключи и значения
по умолчанию сохранены.
