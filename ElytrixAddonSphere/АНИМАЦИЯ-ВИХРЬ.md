# ElytrixAddonSphere 1.35 — что изменилось

## 1. Вихрь поднимается плавно

Было: ease-out (резкий старт, мягкое торможение) за 8 тиков.
Стало: **smoothstep** (`p²(3−2p)`) за `breezeUpTicks: 14` (0.7 с) — мягкий
старт, плавный разгон и плавное торможение у верхней точки.

## 2. Игрок с булавой падает с большей высоты

`maceHeight: 7 → 12` блоков над Вихрем. Падение с ускорением
(`maceFallTicks: 8`), след `FIREWORK` за ним.

## 3. Частицы разделены на две группы

Диагностика показала: частицы были наши, поэтому теперь есть отдельные
выключатели.

```yaml
settings:
  particles: true          # общий выключатель
  particlesAmbient: false  # спираль вихря, следы кольца, дым, атмосфера — ВЫКЛ
  particlesImpact: true    # удары — ВКЛ
```

## 4. Вихрь получает урон от удара булавой

В момент удара:

* `DAMAGE_INDICATOR` — «сердечки урона» над Вихрем;
* `CRIT` — 22 звёздочки, `EXPLOSION`, `SWEEP_ATTACK`, пыль цветом из
  `particleItems` (REDSTONE);
* звук `hurtSound: "ENTITY_GENERIC_HURT"` + взрыв + аметист;
* Вихрь **дрожит** 8 тиков (позиция дёргается на ±0.1 блока) и от удара
  сразу падает.

## 5. Прочие ударные частицы

Приземление: 16 частиц цвета + 8 `FIREWORK` + `EXPLOSION` + 10 `CRIT`,
и расходящееся кольцо радиусом до 3.5 блока (7 точек).

## 6. Настройки

```yaml
settings:
  particles: true
  particlesAmbient: false
  particlesImpact: true
  breezeMode: "BREEZE"     # "VORTEX" — без моба, только спираль частиц
  breezeSpin: 6.0
  breezeRise: 1.6
  mace: true
  maceMaterial: "MACE"
  maceName: "rooyzee"
  maceHeight: 12.0
  winnerOrbitRadius: 1.05
  winnerOrbitSpeed: 8.0
  timings:
    breezeUpTicks: 14
    breezeHoverTicks: 6
    maceFallTicks: 8
    breezeDownTicks: 4
    winnerOrbitTicks: 80
    hurtSound: "ENTITY_GENERIC_HURT"
```

Конфиг: `plugins/BCases/animations/sphere/sphereAnimation.yml`.
Меняешь jar → удали этот файл при выключенном сервере, аддон создаст свежий.

## 7. Сборка

`downloads/ElytrixAnimAddon-1.35.jar` (≈25 КБ), собран ECJ 3.38 под Java 17
против API BCases 1.2 / VirtualEntityApi 1.4.2.
