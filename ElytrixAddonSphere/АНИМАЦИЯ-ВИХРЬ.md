# ElytrixAddonSphere 1.30 — что изменилось

## 1. Игрок с булавой: ник rooyzee + его скин

Виртуальный игрок теперь `maceName: "rooyzee"`, а скин подтягивается
автоматически:

* при старте анимации фоновый поток один раз спрашивает Mojang API
  (`api.mojang.com` → `sessionserver.mojang.com`), получает пару
  value/signature и кэширует её на весь сервер;
* когда игрок с булавой появляется, скин уже применён
  (`VirtualPlayer.setTexture`);
* если интернета нет / ника нет — будет стандартный скин, анимация
  не ломается (запрос с таймаутом 3 с в отдельном потоке).

## 2. Частиц стало мало, и они видны при «Частицы: Меньше»

Раньше частицы сыпались каждый тик (десятки в секунду) — теперь:

| Эффект | Было | Стало |
|---|---|---|
| винтовая искра вокруг Вихря | 3 частицы каждые 2 тика | 1 частица каждые 3 тика |
| облачко у Вихря | каждые 3 тика | каждые 6 тиков |
| след кольца | каждые 2 тика, 3–4 частицы | каждые 5 тиков, 1 частица |
| взрыв при ударе | 70 + 35 | 28 + 10 + 2 взрыва |
| разлёт призов | 8 частиц на приз | 2 частицы (и только у каждого третьего) |
| волна после удара | 16 точек × 10 тиков | 10 точек × 8 тиков |

Плюс важное: `FIREWORK` и `EXPLOSION` — это частицы, которые Minecraft
рисует **даже при настройке «Частицы: Меньше/Минимум»**. Они теперь
используются для главных моментов (искра у Вихря, удар, приземление,
кольцо после удара). `particleVector: FIREWORK` по умолчанию.

## 3. Удар булавой → Вихрь сразу падает

После замаха рукой больше нет паузы: `maceHold = 4` тика, и игрок
исчезает уже во время падения Вихря (его убирает тик-драйвер, а не поток
анимации). Вихрь падает в тот же тик, что и удар.

## 4. Все призы, кроме выигрыша, падают вниз и исчезают

В момент удара булавой (`dropOthers`):

* призы убираются из кольца и начинают резко падать вниз
  с ускорением (6 тиков, до ~2.5 блока);
* имена падают вместе с ними;
* на 6-м тике призы исчезают (у каждого третьего — лёгкое облачко);
* выигрыш остаётся в кольце, а после приземления Вихря выходит на орбиту.

Если `mace: false` — призы падают в момент приземления Вихря.

## 5. Настройки

```yaml
settings:
  particleVector: "FIREWORK"   # видно и при «Частицы: Меньше»
  bobAmplitude: 0.0            # покачивание выключено
  breezeSpin: 6.0
  breezeRise: 1.6
  mace: true
  maceMaterial: "MACE"
  maceName: "rooyzee"
  maceHeight: 7.0
  winnerOrbitRadius: 1.05
  winnerOrbitSpeed: 8.0
  timings:
    breezeUpTicks: 8
    breezeHoverTicks: 6
    maceFallTicks: 8
    breezeDownTicks: 4
    winnerOrbitTicks: 80
```

Старый `sphereAnimation.yml` содержит прежние значения (`maceName: "Mace"`,
`particleVector: "END_ROD"`, `bobAmplitude`) — они перебьют новые.
Удали файл и перезапусти сервер.

## 6. Сборка

`downloads/ElytrixAnimAddon-1.30.jar` (≈23 КБ), собран ECJ 3.38 под Java 17
против API BCases 1.2 / VirtualEntityApi 1.4.2.
