# ElytrixAddonSphere 1.36 — что изменилось

## 1. Частицы снежинок убраны

Из эффектов удара убраны `CRIT` и `FIREWORK` — именно они выглядели как
снежинки. Вместо них **частицы булавы**, как в ванильном mace smash:

```yaml
settings:
  maceParticle: "GUST_EMITTER_LARGE"  # большой порыв ветра (1.21+)
  gustParticle: "GUST"                # порывы
  smokeParticle: "WHITE_SMOKE"        # белый дым (1.21.4)
```

Используются: `GUST_EMITTER_LARGE` (1 шт в точке удара), `GUST` (3),
`WHITE_SMOKE` (4), `SWEEP_ATTACK` (1 — взмах), пыль `REDSTONE` (4).
Количество уменьшено: удар читается, но не заливает экран.
Если сервер не знает частицу — тихо берётся `CLOUD`.

То же на приземлении: `GUST_EMITTER_LARGE` + `GUST` + `WHITE_SMOKE`,
а «волна» по кругу теперь из `GUST`, а не из `FIREWORK`.

Заодно `particleVector` по умолчанию `SMOKE` (след кольца), чтобы при
включении атмосферы снежинки не вернулись.

## 2. Вихрь поднимается выше и сразу бодро

```yaml
settings:
  breezeRise: 2.4        # было 1.6
  timings:
    breezeUpTicks: 20    # 1 секунда
```

Кривая подъёма — **ease-out**: первые тики Вихрь идёт быстро (раньше
smoothstep стартовал вяло), у верхней точки мягко тормозит.

## 3. Булава бьёт ровно в верхней точке

Раньше: подъём заканчивался → пауза `breezeHoverTicks` → падала булава.
Теперь игрок стартует сверху так, чтобы долететь **точно к моменту, когда
подъём завершается**: удар обрывает подъём, Вихрь не висит в воздухе.

```yaml
timings:
  breezeHoverTicks: 0   # больше не используется
  maceFallTicks: 8      # падение игрока; старт считается автоматически
```

## 4. Группы частиц

```yaml
settings:
  particles: true
  particlesAmbient: false   # спираль вихря, следы, дым — выкл
  particlesImpact: true     # удар булавы, приземление, разлёт — вкл
```

## 5. Сценарий

Кольцо призов → подъём (1 с, 2.4 блока; сразу бодрый старт) → на верхней
точке сверху врезается игрок **rooyzee** со скином и булавой (12 блоков) →
удар: порыв ветра, `SWEEP_ATTACK`, звук урона, Вихрь дрожит 8 тиков и падает →
остальные призы резко падают и исчезают → приземление (порыв + дым) и орбита
приза 4 с.

## 6. Сборка

`downloads/ElytrixAnimAddon-1.36.jar` (≈25 КБ), собран ECJ 3.38 под Java 17
против API BCases 1.2 / VirtualEntityApi 1.4.2.

Конфиг: `plugins/BCases/animations/sphere/sphereAnimation.yml` — после
замены jar удали его при выключенном сервере, аддон создаст свежий.
