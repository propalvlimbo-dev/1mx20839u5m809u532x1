# NoSpears 1.0.0

Полностью убирает **копья** (добавлены в Minecraft 1.21.11) с сервера.

## Что делает

| Где | Что |
| --- | --- |
| Крафт | результат крафта копья обнуляется — скрафтить нельзя |
| Сундуки/лут | копья вырезаются из любого сгенерированного лута (сундуки, награды, бартер) |
| Земля | выпавшее копьё не появляется |
| Мобы | с зомби/пиглинов и прочих копьё снимается при спавне |
| Игроки | при входе копья удаляются из инвентаря и рук |

Определение копья — любой материал с именем, оканчивающимся на `_SPEAR`
(`wooden_spear`, `iron_spear`, `copper_spear`, `diamond_spear`,
`netherite_spear`, `golden_spear`, `stone_spear`).

## Установка

1. `downloads/NoSpears-1.0.0.jar` → в `plugins/`
2. Перезапуск сервера
3. Настройки — `plugins/NoSpears/config.yml` (всё включено по умолчанию)

## Команда

```
/nospears          — вычистить копья у всех онлайн-игроков
/nospears reload   — перечитать конфиг
```
Право: `nospears.admin` (по умолчанию op).

## Важно

- Плагин не удаляет копья из уже сгенерированных сундуков в мире — только из
  тех, что заполняются при открытии/генерации лута. Старые сундуки с копьями
  можно почистить только вручную.
- Бартер пиглинов и торговля идут через лут-таблицы, поэтому тоже чистятся.
