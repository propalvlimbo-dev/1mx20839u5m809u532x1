# ElytrixSeller

Исходный код ElytrixSeller (rSeller 2.0.2-ElytriX), продающего предметы вручную и через автоскупку.
Исходная сборка совместима с Java 16 и компилируется против Paper/Spigot API 1.16.5; новые материалы
из конфигов распознаются на серверах, где они есть (вплоть до Paper 1.21.11).

## Расширенные товары

- В `locale/ru/resources/items.yml` и `locale/en/resources/items.yml` добавлены семена, урожай, Nether Wart,
  ягоды, грибы, сахарный тростник, какао-бобы, незерские растения, новые садовые растения и саженцы.
  Сохранены уже настроенные цены; для новых позиций добавлены небольшие базовые цены и очки.
- Автоскупка получила категорию `farms` с урожаем, семенами, выращиваемыми растениями и товарами с ферм.
- В `ores` добавлены сырьевые руды, медные и аметистовые материалы, а также блоки руд, включая варианты
  из глубинного сланца.
- В `mobs` добавлены новые материалы и трофеи: рога козы, светолягушатники, предметы аксолотля и головастика,
  лут Бриза, Броненосца, Скрипуна и испытательных камер; сохранены старые выпадения и трофеи.
- `ItemsConfig` учитывает переименование `SCUTE` в `TURTLE_SCUTE`, чтобы конфиг продолжал работать
  на старых и новых версиях API.

## Обновление существующего сервера

Резервируйте текущие конфиги перед обновлением. Плагин не перезаписывает существующие файлы:
перенесите только недостающие ключи и цены из соответствующего `locale/<язык>/resources/items.yml` в
`plugins/ElytrixSeller/items.yml`; объедините новые ID в списках `ores` и `mobs` и добавьте категорию
`farms` из соответствующего `config.yml`, сохранив свои цены и настройки. В действующий
`plugins/ElytrixSeller/GUI/autoSellGUI.yml` добавьте кнопку `category_farms` из
`src/main/resources/GUI/autoSellGUI.yml`; при совпадении слотов с вашими кнопками сдвиньте их.
После объединения перезагрузите конфиги командой `/rseller reload` или перезапустите сервер.

## Инициализация базы данных

В версии 2.0.1 создание и миграция таблиц игроков и логов завершаются синхронно при включении плагина, до регистрации обработчиков и периодических сохранений. Это исправляет startup-ошибку `no such table`. Если схема не создаётся, плагин прекращает инициализацию; после успеха в логе появляются `[DB] Player table ready: <table>` и `[DB] Sell log table ready: <table>`. Отдельная гонка асинхронной загрузки/сохранения PlayerData ещё не исправлена; live DB-тест не проводился.

## Кнопки меню

В версии 2.0.2 клики по занятым слотам GUI отменяют перемещение предметов, но больше не прерывают обработку кнопки. Это позволяет действиям `opengui` переходить из главного меню в автоскупку и универсальный скупщик.
