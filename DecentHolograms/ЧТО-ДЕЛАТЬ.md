# Голограммы: что делать сейчас

## 1. Выключить старые (главное)

На скрине видно **две** голограммы: новая (без фона) и старая (с серыми плашками).
Старые остались включёнными — они и висят поверх.

В консоли или в игре:

```
dh h disable addvk
dh h disable cases
dh h disable don
dh h disable don1
dh h disable hello
dh h disable helps
```

Или просто удалить/переименовать файлы в `plugins/DecentHolograms/holograms/`:

```
plugins/DecentHolograms/holograms/addvk.yml
plugins/DecentHolograms/holograms/cases.yml
plugins/DecentHolograms/holograms/don.yml
plugins/DecentHolograms/holograms/don1.yml
plugins/DecentHolograms/holograms/hello.yml
plugins/DecentHolograms/holograms/helps.yml
```

→ переименовать папку `holograms` в `holograms_old` и `/dh reload`.
Старые файлы в репозитории остаются как исходник — на сервере они не нужны.

Проверка: `/dh h list` — у всех должно быть `disabled`, `/dh displays list` — 11 записей.

## 2. Якорь

У `text_display` точка привязки — **низ** блока текста, а у старой голограммы —
**верхняя строка**. Поэтому в файлах стоит компенсирующее смещение:

| Голограмма | Строк | `translation y` |
|---|---|---|
| `addvk` | 8 | `-1.80` |
| `cases` | 5 | `-1.12` |
| `don` / `don1` | 17 | `-3.83` |
| `hello` | 10 | `-2.25` |
| `helps` | 12 | `-2.70` |

Сейчас верхняя строка стоит ровно там, где был якорь старой голограммы.

Подогнать по месту (в игре, у нужной голограммы):

```
/dh displays movehere don              # поставить якорь туда, где стоишь (смещение сохранится)
/dh displays attribute don translation 0 0 0   # без смещения: текст уйдёт выше
/dh displays attribute don translation 0 -4.2 0 # поднять/опустить
/dh displays teleport don              # посмотреть, где реально якорь
```

## 3. Отступы строк

У нового типа шаг строк фиксированный — 0.225 блока (9 px шрифта). У старых
голограмм между строками было 0.3, поэтому блок стал компактнее: верх совпадает,
низ будет чуть выше, чем раньше. Это не сбитый якорь, а другой шаг строк —
у `text_display` его нельзя задать отдельно.

Если нужно точь-в-точь как раньше (с пустыми строками-отступами) — в файле
добавь пустые строки `- ' '` между блоками, шаг останется 0.225.

## 4. Иконки

Предметы (`chest`, `gold_block`, `book`) — отдельные файлы `*_icon.yml`,
стоят под текстом (`translation y` = низ блока − 0.35).

## 5. Фон

Сейчас `alpha: 0` — фона нет совсем, как на втором скрине.

Если когда-нибудь понадобится:

```
/dh displays attribute hello background-color RGBA 8 8 12 150
```

Ровный «квадрат» — папка `panels/` (бетон за текстом), подключается отдельно.
