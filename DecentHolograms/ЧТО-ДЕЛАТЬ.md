# Голограммы: что делать сейчас

## 1. Выключить старые (главное)

На скрине видно **две** голограммы: новая (без фона) и старая (с серыми плашками).
Старые остались включёнными — они и висят поверх.

В консоли или в игре:

```
dh h disable addvk
dh h disable cases
dh h disable don
dh h disable don1
dh h disable hello
dh h disable helps
```

Или просто удалить/переименовать файлы в `plugins/DecentHolograms/holograms/`:

```
plugins/DecentHolograms/holograms/addvk.yml
plugins/DecentHolograms/holograms/cases.yml
plugins/DecentHolograms/holograms/don.yml
plugins/DecentHolograms/holograms/don1.yml
plugins/DecentHolograms/holograms/hello.yml
plugins/DecentHolograms/holograms/helps.yml
```

→ переименовать папку `holograms` в `holograms_old` и `/dh reload`.
Старые файлы в репозитории остаются как исходник — на сервере они не нужны.

Проверка: `/dh h list` — у всех должно быть `disabled`, `/dh displays list` — 11 записей.

## 2. Якорь и поворот

* `translation: 0` — верхняя строка стоит ровно в точке `location`, строки идут
  вниз (так же, как было у старой голограммы). Никаких смещений больше нет.
* `billboard: VERTICAL` — голограмма поворачивается только вокруг вертикали,
  при взгляде вниз/вверх не заваливается (раньше был `CENTER` — из-за него
  «слишком сильно поворачивается»).
* `addvk` и `helps` — `billboard: FIXED`, стоят намертво, не двигаются вообще.

Подогнать по месту:

```
/dh displays movehere don                 # якорь туда, где стоишь
/dh displays attribute don translation 0 -0.5 0   # сместить
/dh displays attribute don billboard FIXED        # заморозить
/dh displays attribute don billboard CENTER       # вернуть, как было
```

Шаг строк фиксированный — 0.225 блока (9 px). Меняется только масштабом:
`/dh displays attribute don scale 1.2`.

## 3. Иконки под текстом

Предметы (`chest`, `gold_block`, `book`) — отдельные файлы `*_icon.yml`,
`display-type: GUI` (плоская иконка, как у старой голограммы), стоят сразу
под последней строкой.

Если не видно — проверить и подвинуть:

```
/dh displays list                 # должно быть 11 записей, в т.ч. hello_icon
/dh displays tp hello_icon        # телепорт к иконке
/dh displays attribute hello_icon scale 1.5
/dh displays attribute hello_icon translation 0 -2.7 0
```

## 5. Фон

Сейчас `alpha: 0` — фона нет совсем, как на втором скрине.

Если когда-нибудь понадобится:

```
/dh displays attribute hello background-color RGBA 8 8 12 150
```

Ровный «квадрат» — папка `panels/` (бетон за текстом), подключается отдельно.
