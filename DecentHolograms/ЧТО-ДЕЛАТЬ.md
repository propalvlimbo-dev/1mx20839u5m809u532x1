# Голограммы: что делать сейчас

## 1. Выключить старые

На скринах видно **две** голограммы: новая (без фона) и старая (с серыми плашками).
Старые остались включёнными — они и висят поверх.

```
dh h disable addvk
dh h disable cases
dh h disable don
dh h disable don1
dh h disable hello
dh h disable helps
```

Или переименовать папку `plugins/DecentHolograms/holograms` → `holograms_old`, `/dh reload`.
Проверка: `/dh h list` — все `disabled`; `/dh displays list` — 11 записей.

## 2. Высота

`text_display` растёт **вверх** от точки привязки, поэтому в файлах точка опущена
на высоту блока — **верхняя строка стоит ровно в старом якоре**, дальше строки идут вниз.

| Голограмма | Строк | `translation y` |
|---|---|---|
| `addvk` (безопасность) | 8 | -1.80 |
| `cases` (кейсы) | 5 | -1.12 |
| `don` / `don1` | 17 | -4.73 |
| `hello` | 10 | -2.60 |
| `helps` | 12 | -3.05 |

`don`/`don1` опущены на 0.9, `hello`/`helps` на 0.35;
`cases` и `addvk` оставлены как были.

Всё ещё высоко/низко — двигать так (минус = ниже):

```
/dh displays attribute hello translation 0 -2.7 0
```

Шаг строк фиксированный 0.225 блока, отдельно не настраивается.

## 3. Поворот

* все голограммы — `billboard: VERTICAL`: поворачиваются за игроком только вокруг
  вертикали, при взгляде вниз не заваливаются.
  `helps` и `addvk` были `FIXED`, но статичную голограмму всегда видно только
  с одной стороны (с обратной — пусто/зеркально), поэтому тоже `VERTICAL`.
  Вернуть статику: `/dh displays attribute helps billboard FIXED`.

Направления: `0` — юг (+Z), `90` — запад, `180` — север, `270` — восток.

```
/dh displays attribute helps yaw 0
/dh displays attribute helps yaw 90
/dh displays attribute helps yaw 180
/dh displays attribute helps yaw 270
```
подобрать нужное и записать это же число в `location.yaw` файла.

## 4. Предметы (иконки)

`billboard: VERTICAL`, `display-type: FIXED`.
У `hello`, `cases`, `addvk` иконка стоит **сбоку** (слева от текста),
у `don`, `don1`, `helps` — под текстом.

| Файл | Предмет | Масштаб | `x` | `y` |
|---|---|---|---|---|
| `addvk_icon` | `minecraft:shield` | 0.9 | -1.20 | -0.90 |
| `cases_icon` | `minecraft:ominous_trial_key` | 0.5 | -1.20 | -0.56 |
| `hello_icon` | `minecraft:knowledge_book` | 0.6 | -1.20 | -1.48 |
| `don_icon` | `minecraft:heavy_core` | 0.8 | 0 | -5.28 |
| `don1_icon` | `minecraft:resin_block` | 0.8 | 0 | -5.28 |
| `helps_icon` | `minecraft:command_block` | 0.7 | 0 | -3.60 |

Сбоку у всех трёх есть `z: 0.45` — предмет вынесен вперёд, чтобы не тонул
в стене/тексте.

Подогнать сторону:

```
/dh displays attribute cases_icon translation -1.2 -0.56 0.45   # слева (сейчас)
/dh displays attribute cases_icon translation 1.2 -0.56 0.45    # справа
/dh displays attribute cases_icon translation -1.8 -0.56 0.45   # дальше
/dh displays attribute cases_icon translation -1.2 0.0 0.45     # выше (к заголовку)
```

Масштаб — размер предмета: `0.6` мелкий, `1.0` ~ полблока, `2.0` огромный.

**Важно:** материал только в формате Mojang, строчными:
`item: 'minecraft:book'`. `BOOK` / `CHEST` плагин не принимает
(`Found invalid item type 'BOOK'`).

```
/dh displays attribute hello_icon scale 0.5      # мельче
/dh displays attribute hello_icon translation 0 -3.0 0
```

## 5. Фон

`alpha: 0` — фона нет совсем. Если понадобится:

```
/dh displays attribute hello background-color RGBA 8 8 12 150
```

Ровный «квадрат» — папка `panels/` (бетон за текстом), подключается отдельно.
