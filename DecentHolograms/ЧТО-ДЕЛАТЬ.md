# Голограммы: что делать сейчас

## 1. Выключить старые

На скринах видно **две** голограммы: новая (без фона) и старая (с серыми плашками).
Старые остались включёнными — они и висят поверх.

```
dh h disable addvk
dh h disable cases
dh h disable don
dh h disable don1
dh h disable hello
dh h disable helps
```

Или переименовать папку `plugins/DecentHolograms/holograms` → `holograms_old`, `/dh reload`.
Проверка: `/dh h list` — все `disabled`; `/dh displays list` — 11 записей.

## 2. Высота

`text_display` растёт **вверх** от точки привязки, поэтому в файлах точка опущена
на высоту блока — **верхняя строка стоит ровно в старом якоре**, дальше строки идут вниз.

| Голограмма | Строк | `translation y` |
|---|---|---|
| `addvk` | 8 | -1.80 |
| `cases` | 5 | -1.12 |
| `don` / `don1` | 17 | -3.83 |
| `hello` | 10 | -2.25 |
| `helps` | 12 | -2.70 |

Всё ещё высоко/низко — двигать так (минус = ниже):

```
/dh displays attribute hello translation 0 -2.7 0
```

Шаг строк фиксированный 0.225 блока, отдельно не настраивается.

## 3. Поворот

* `hello`, `cases`, `don`, `don1` — `billboard: VERTICAL`: крутятся за игроком
  только вокруг вертикали, при взгляде вниз не заваливаются.
* `addvk`, `helps` — `billboard: FIXED`: стоят намертво.
* `helps` развёрнут на 180° (`location.yaw: 180.0`) — смотрит в другую сторону.

```
/dh displays attribute helps yaw 90        # довернуть
/dh displays attribute hello billboard FIXED   # заморозить
```

## 4. Предметы (иконки)

`cases_icon` (chest), `don_icon` / `don1_icon` (gold_block),
`hello_icon` / `helps_icon` (book) — отдельные ITEM-дисплеи, `billboard: VERTICAL`,
`display-type: FIXED`, `scale: 1.2`, стоят сразу под последней строкой.

**Важно:** материал пишется в формате Mojang, строчными буквами:
`item: 'minecraft:book'`, `block: 'minecraft:black_concrete'`.
`BOOK` / `CHEST` / `BLACK_CONCRETE` плагин не принимает —
`Found invalid item type 'BOOK'`.

Если не видно:

```
/dh displays list                  # должно быть 11 записей, в т.ч. hello_icon
/dh displays tp hello_icon         # телепорт к иконке — сразу видно, где она
/dh displays attribute hello_icon translation 0 -2.8 0   # поднять/опустить
/dh displays attribute hello_icon scale 2                # крупнее
```

Если `hello_icon` в списке нет — сервер не загрузил файл, смотри консоль
на `Failed to load display config 'hello_icon.yml'`.

## 5. Фон

`alpha: 0` — фона нет совсем. Если понадобится:

```
/dh displays attribute hello background-color RGBA 8 8 12 150
```

Ровный «квадрат» — папка `panels/` (бетон за текстом), подключается отдельно.
