# Твои голограммы в новом стиле (Displays)

Ты залил `DecentHolograms/` — я переделал **все 6 голограмм** из старого типа
(armor stand) в новый тип **Displays** (display-сущности Minecraft, `2.10+`).
Текст, цвета, цены и ссылки — **1:1**, координаты те же.

```
holograms/ (было)          displays/ (стало)
├── addvk.yml      ->      ├── addvk.yml
├── cases.yml      ->      ├── cases.yml + cases_icon.yml
├── don.yml        ->      ├── don.yml + don_icon.yml
├── don1.yml       ->      ├── don1.yml + don1_icon.yml
├── hello.yml      ->      ├── hello.yml + hello_icon.yml
└── helps.yml      ->      └── helps.yml + helps_icon.yml
```

Отдельные `*_icon.yml` — потому что новый тип не умеет смешивать текст и предмет
в одной голограмме: строки `#ICON: chest / gold_block / book` стали отдельными
предметными дисплеями, которые стоят ровно там же, где были (высота посчитана
по старым `height`).

---

## Что получилось

| Голограмма | Координаты (spawn) | Строк | Смещение Y | Иконка |
|---|---|---|---|---|
| `addvk` — безопасность/Telegram | `82.500 / 53.500 / -25.500` | 8 | `-1.90` | — |
| `cases` — кейсы | `41.611 / 52.900 / 0.564` | 5 | `-1.00` | `CHEST` |
| `don` — привилегии | `0.528 / 61.400 / 11.462` | 17 | `-4.40` | `GOLD_BLOCK` |
| `don1` — привилегии (2-я стойка) | `0.392 / 61.400 / -10.550` | 17 | `-4.40` | `GOLD_BLOCK` |
| `hello` — информация | `11.408 / 59.400 / 0.437` | 10 | `-2.40` | `BOOK` |
| `helps` — команды сервера | `-10.444 / 60.000 / 0.535` | 12 | `-3.10` | `BOOK` |

Почему смещение по Y: у `text_display` текст растёт **вверх** от точки привязки,
а у старых голограмм точка — это верхняя строка. Поэтому точка привязки опущена
на высоту блока (сумма старых `height`), чтобы текст висел там же, где раньше.

Оформление у всех одинаковое: прозрачная плашка (`alpha: 0`), тень текста,
`billboard: CENTER` (поворачивается к игроку), `line-width: 1000`
(длинные строки с `799₽`, `279₽` не переносятся), `scale: 1`.

## Установка (5 минут)

1. Обнови плагин до **2.10.2** (1.21.11 поддержан с 2.9.9, Displays — с 2.10.0):
   [DecentHolograms-2.10.2.jar](https://github.com/DecentSoftware-eu/DecentHolograms/releases/download/2.10.2/DecentHolograms-2.10.2.jar)
2. Залей папку `displays/` в `plugins/DecentHolograms/displays/`.
3. `/dh reload` → `/dh displays list` — должно быть 11 записей (6 текстовых + 5 иконок).
4. **Выключи старые**, иначе будут висеть две одинаковые:

```
/dh h disable addvk
/dh h disable cases
/dh h disable don
/dh h disable don1
/dh h disable hello
/dh h disable helps
```

5. Подойди к каждой точке и проверь. Если вдруг съехала по высоте —
   см. раздел «Если текст стоит не там» ниже.

Кнопку «Закрыть» и прочее трогать не надо — это только голограммы.

---

## Если текст стоит не там

Все правки — без перезапуска, командой в игре:

```
# вернуть точку привязки на исходные координаты (без смещения)
/dh displays attribute addvk translation 0 0 0

# поднять/опустить на N блоков
/dh displays attribute addvk translation 0 0.5 0

# поставить заново там, где стоишь (смещение сохранится)
/dh displays movehere addvk

# сбросить любое значение к дефолту
/dh displays reset-attribute addvk translation
```

Полезное:

```
/dh displays list                 — все дисплеи
/dh displays nearby               — что рядом (удобно искать нужную)
/dh displays setline hello 3 &fРежим: &#F8BEFBГриферский №2
/dh displays addline hello &7Новая строка
/dh displays removeline hello 12
/dh displays scale ... / display-range ... / update-interval ...
/dh displays delete <имя>
```

## Атрибуты нового типа

| Атрибут | Значение | Что делает |
|---|---|---|
| `billboard` | `CENTER` / `VERTICAL` / `HORIZONTAL` / `FIXED` | поворот к игроку |
| `background-color` | `rgba` (red, green, blue, alpha) | плашка под текстом (`alpha: 0` = нет) |
| `text-shadow` | `true` / `false` | тень текста |
| `see-through` | `true` / `false` | видно сквозь блоки |
| `alignment` | `LEFT` / `CENTER` / `RIGHT` | выравнивание |
| `line-width` | число | перенос строк |
| `text-opacity` | `0–255` | прозрачность текста |
| `scale` | `x y z` | размер |
| `translation` | `x y z` | смещение от координаты |
| `yaw` / `pitch` | градусы | поворот |
| `brightness` | `block-light`, `sky-light` | своя яркость |
| `glow-color` | `rgba` | свечение |
| `display-type` (только ITEM) | `FIXED` / `GUI` / `GROUND` / `HEAD` / `NONE` / `*_HAND` | как рисуется предмет |

Плашка под текстом, если понадобится:

```
/dh displays attribute hello background-color RGBA 8 8 12 64
```

---

## Ограничения нового типа

* тип (`TEXT` / `ITEM` / `BLOCK`) задаётся при создании и не меняется;
* **нет страниц и кликов** (`pages`, `actions`) — только у старых голограмм;
* текст и предмет — только отдельными дисплеями (поэтому `*_icon.yml`);
* `#ICON:` / `#HEAD:` / `#SMALLHEAD:` / `#ENTITY:` / `#EMPTY:` в тексте не работают.

## Конвертер (если появятся новые старые голограммы)

`tools/dh2displays.py` — то, чем сделаны эти файлы (нужен Python 3 + `pip install pyyaml`):

```bash
python3 tools/dh2displays.py DecentHolograms/holograms DecentHolograms/displays
```

`tools/dh2displays.ps1` — то же для Windows/PowerShell (только текст, иконки
пропускает и пишет, сколько пропустил).

## Команды и плейсхолдеры

| Что | Как |
|---|---|
| Цвета | `&7`, `&f`, `&l` |
| HEX | `&#F8BEFB` (как в твоих файлах) или `#F8BEFB` |
| Градиент | `<#F8BEFB>текст</#E8FFF0>` |
| Радуга | `<RAINBOW100>текст</RAINBOW>` |
| Ник игрока | `{player}` (встроенный) или `%player_name%` (PlaceholderAPI) |
| Место в списке | `%server_online%` и любые PAPI-плейсхолдеры |

`%player_name%` в `don`/`don1` оставлен как был — работает при установленном PlaceholderAPI.

## Если что-то не так

* **Висят две голограммы** — старая не выключена: `/dh h disable <имя>`.
* **Ничего не видно** — `/dh displays list`, проверь `enabled: true` и `display-range`.
* **Не загрузился файл** — в консоли `Failed to load display config '<файл>'`:
  проверь YAML (отступы в 2 пробела), либо `/dh displays delete <имя>` и залей заново.
* **Иконка не появилась** — проверь `item:` в `*_icon.yml` (`CHEST`, `GOLD_BLOCK`, `BOOK`).

## Фон

Клиент рисует фон `text_display` **построчно** (плашка = ширина строки), поэтому
один общий прямоугольник «из коробки» не умеет ни один плагин. В `displays/`
уже включён большой фон: **все строки добиты пробелами до одной ширины**, плашки
складываются в ровный прямоугольник, `alpha: 150`.

Текст не менялся — пробелы только по краям, строки по центру.

```
/dh displays attribute hello background-color RGBA 8 8 12 150   # плотнее
/dh displays attribute hello background-color RGBA 8 8 12 64    # полупрозрачнее
/dh displays attribute hello background-color RGBA 8 8 12 0     # убрать фон
```

Размер квадрата = ширина самой длинной строки (`hello` ≈ 4.3 блока, `don` ≈ 6.1).
Шире — добавить пробелов в конец строк в файле (или `python3 tools/make_boxes.py`).

Если нужен точный размер и любой цвет — папка `panels/`: отдельный `BLOCK`-дисплей
(бетон) позади текста. Скопировать в `displays/`, `/dh reload`.

* материал: `block: 'BLACK_CONCRETE'` → `BLACK_TERRACOTTA`, `BLACK_STAINED_GLASS`;
* размер: `scale.x` / `scale.y`;
* перекрывает текст → `translation.z: 0.06`.
