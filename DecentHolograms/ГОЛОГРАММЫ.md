# Голограммы: новый стиль (Displays) вместо armor stand

Коротко: **менять плагин не надо.** В DecentHolograms с версии **2.10.0** появился второй тип
голограмм — на **display-сущностях Minecraft** (`text_display`, `item_display`, `block_display`,
появились в 1.19.4). Это и есть «новый стиль», про который ты слышал.

- 1.21.11 поддерживается начиная с **2.9.9**;
- новый тип (Displays) — с **2.10.0**;
- актуальная версия — **2.10.2** (18.10.2026): <https://github.com/DecentSoftware-eu/DecentHolograms/releases/download/2.10.2/DecentHolograms-2.10.2.jar>

Старые голограммы никуда не исчезают: у нового типа **своя папка** `plugins/DecentHolograms/displays/`
и **своя команда** `/dh displays ...`. Оба типа работают одновременно, поэтому после переноса
старые нужно выключить, иначе будет дубль.

---

## Что даёт новый тип

| Возможность | Атрибут | Значение |
|---|---|---|
| Плашка под текстом | `background-color` | `rgba` (r,g,b,a) |
| Тень текста | `text-shadow` | `true/false` |
| Видно сквозь блоки | `see-through` | `true/false` |
| Выравнивание | `alignment` | `LEFT` / `CENTER` / `RIGHT` |
| Ширина строки (перенос) | `line-width` | число (по умолчанию 300) |
| Прозрачность текста | `text-opacity` | 0–255 |
| Размер | `scale` | `x, y, z` |
| Поворот | `yaw`, `pitch` | градусы |
| Смещение | `translation` | `x, y, z` |
| Поворот к игроку | `billboard` | `CENTER` / `VERTICAL` / `HORIZONTAL` / `FIXED` |
| Свечение | `glow-color` | `rgba` |
| Яркость | `brightness` | `block-light`, `sky-light` |
| Тень-круг | `shadow-radius`, `shadow-strength` | числа |

Плюс многострочный текст в одной сущности и отсутствие армор-стоек: плагин отправляет
display-сущность клиенту пакетами, реальных entity в мире нет.

**Ограничения** (важно при переносе):

* тип (`TEXT` / `ITEM` / `BLOCK`) задаётся при создании и не меняется;
* нет страниц (`pages`) и кликов (`actions`) — это только у старого типа;
* нельзя смешать текст и предмет в одной голограмме — предметы делаются отдельным
  `ITEM`-дисплеем рядом.

---

## 1. Обновление плагина

1. Сделай бэкап `plugins/DecentHolograms/` (папки `holograms/`, `displays/`, `config.yml`).
2. Замени `DecentHolograms-*.jar` на **2.10.2**.
3. Перезапусти сервер (не `/reload`).
4. Появится папка `plugins/DecentHolograms/displays/`.

---

## 2. Перенос старых голограмм

### Вариант А — конвертер (быстро, для всех сразу)

В репозитории лежит `tools/dh2displays.ps1`. Он читает старые `holograms/*.yml`
и пишет новые `displays/*.yml`.

Проще всего запустить его прямо из папки плагина — тогда пути по умолчанию
(`holograms` и `displays` рядом) подойдут сами:

```powershell
cd C:\server\plugins\DecentHolograms
C:\путь\к\репозиторию\tools\dh2displays.ps1 -DryRun
```

Или с явными путями:

```powershell
cd C:\путь\к\репозиторию\tools

# посмотреть, что получится, ничего не записывая
.\dh2displays.ps1 -Source "C:\server\plugins\DecentHolograms\holograms" `
                  -Destination "C:\server\plugins\DecentHolograms\displays" -DryRun

# сконвертировать
.\dh2displays.ps1 -Source "C:\server\plugins\DecentHolograms\holograms" `
                  -Destination "C:\server\plugins\DecentHolograms\displays"
```

Параметры:

| Параметр | Что делает |
|---|---|
| `-BackgroundAlpha 64` | полупрозрачная плашка под текстом (0 = без плашки, по умолчанию) |
| `-SeeThrough` | текст видно сквозь блоки |
| `-NoShadow` | выключить тень |
| `-Force` | перезаписать уже существующие файлы в `displays` |
| `-DryRun` | только показать результат |

Что переносится: все **текстовые** строки первой страницы, координаты, `display-range`,
`update-interval`, `enabled`. Цвета `&`, `#RRGGBB`, градиенты — как есть.

Что не переносится: страницы, клики и строки `#ICON:` / `#HEAD:` / `#SMALLHEAD:` /
`#ENTITY:` / `#EMPTY:` — скрипт их пропускает и пишет в консоль, сколько пропустил.
Вместо них делается отдельный предметный дисплей:

```
/dh displays create item <имя> DIAMOND_SWORD
/dh displays attribute <имя> display-type <GUI|GROUND|FIXED>
```

После конвертации:

```
/dh reload
/dh displays list
/dh displays nearby
```

Проверь каждую, при необходимости подвинь: `/dh displays movehere <имя>`.
Старые потом выключи: `/dh h disable <имя>` (или убери файлы из `holograms/`).

### Вариант Б — вручную

```
/dh displays create text spawn &f☁ <#F8BEFB>ᴇʟʏᴛʀɪx</#E8FFF0>
/dh displays addline spawn &7Добро пожаловать, <#F8BEFB>{player}</#E8FFF0>!
/dh displays setline spawn 1 &fНовая первая строка
/dh displays attribute spawn background-color RGBA 8 8 12 64
/dh displays attribute spawn billboard CENTER
/dh displays attribute spawn scale 1.2
/dh displays attribute spawn text-shadow true
/dh displays movehere spawn
```

## 3. Готовые голограммы в этом репозитории

В `DecentHolograms/displays/` лежат четыре новых голограммы в стиле elytrix:

| Файл | Где ставить |
|---|---|
| `spawn.yml` | спавн — приветствие, `/kit`, `/menu`, Discord |
| `auction.yml` | вход в аукцион — `/ah` |
| `kits.yml` | зона наборов — `/kit` |
| `donate.yml` | донат-зона — Telegram/Discord |

Как поставить:

1. Скопируй файлы в `plugins/DecentHolograms/displays/`.
2. `/dh reload`
3. Поставь каждую на своё место: `/dh displays movehere spawn`, `/dh displays movehere auction` и т.д.
4. Текст правится в игре: `/dh displays setline <имя> <номер строки> <текст>`.

Внутри — градиент `<#F8BEFB>…</#E8FFF0>`, разделители `▪`, `{player}`, прозрачная плашка
(`alpha: 0`) и тень. Хочешь плашку — поменяй `alpha` на 64–110 или командой
`/dh displays attribute <имя> background-color RGBA 8 8 12 64`.

## 4. Цвета и подстановки

| Что | Как |
|---|---|
| Обычные цвета | `&7`, `&f`, `&l` |
| HEX | `#F8BEFB` или `&#F8BEFB` |
| Градиент | `<#F8BEFB>текст</#E8FFF0>` |
| Радуга | `<RAINBOW100>текст</RAINBOW>` |
| Ник игрока | `{player}` |
| PlaceholderAPI | `%player_name%`, `%server_online%` и т.д. (если стоит PAPI) |

## 5. Частые проблемы

* **Голограмма не видна** — `display-range` (по умолчанию 256 у дисплеев и 48 у старых),
  проверь `enabled: true` и `/dh displays list`.
* **Висят две одинаковые** — старая и новая: `/dh h disable <имя>`.
* **Текст внутри стены** — `/dh displays movehere <имя>`.
* **Не подхватился файл** — имя файла = имя голограммы, только `.yml`, без вложенных папок.
* **Сломался YAML** — плагин пишет в консоль `Failed to load display config '<файл>'`;
  проще пересоздать `/dh displays delete <имя>` и залить файл заново.
