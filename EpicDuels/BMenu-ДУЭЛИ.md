# Меню дуэлей в BMenu (стиль ElytriX)

Своё меню поверх EpicDuels: те же рамки, звуки и анимация сборки, что в
главном меню сервера. Игрок видит кнопки с объяснением, а не английское GUI.

## Что в комплекте

```
plugins/BMenu/menu/elytrix/duel/
├── duel.yml         главное меню дуэлей
├── queue.yml        выбор кита для очереди
├── help.yml         «Как играть», 4 шага
├── stats.yml        профиль и топ
├── rounds.yml       число раундов: 1 / 3 / 5
├── kit.yml          выбор кита (те же 9 китов, что в queue.yml)
└── confirm.yml      подтверждение боя / постановка пары в очередь
```

Плюс мост `ElytrixDuelsBridge-1.2.0.jar`: он подменяет окна самого
EpicDuels на эти меню и рисует своё окно выбора игрока. Без моста `/duel` показывает меню плагина
(перекрашенное, но без анимации BMenu).

`BMenu/config.yml` — добавлены команды открытия:

```
/duels        (/дуэли)
/duelshelp    (/дуэлипомощь)
```

## Установка

1. Скопировать папку `elytrix/duel` в `plugins/BMenu/menu/elytrix/`.
2. В `plugins/BMenu/config.yml` в `open_commands` добавить блок:

```
  duels:
    menu: elytrix:duel
    aliases:
      - duels
      - дуэли
  duel_help_menu:
    menu: elytrix:duel_help
    aliases:
      - duelshelp
      - дуэлипомощь
```

3. Положить `ElytrixDuelsBridge-1.2.0.jar` в `plugins/` (нужны `EpicDuels`
   и `BMenu`).
4. Перезагрузить сервер.
5. Проверить: `/duel` — должно открыться наше меню с анимацией.

## Что делает каждая кнопка

### Главное меню (`elytrix:duel`)

| Слот | Кнопка | Действие |
|---|---|---|
| 4 | Твой профиль | победы, поражения, процент, очки — цифры мост передаёт сам |
| 20 | Дуэль 1 на 1 | `/duel duels` — выбор игрока |
| 21 | Бои 2 на 2 | выбор напарника → кит → очередь пар |
| 22 | Поиск соперника | наше меню с китами → `/duel queue <кит>` |
| 23 | Статистика | открывает `elytrix:duel_stats` |
| 24 | Рейтинг | `/duel leaderboard wins` |
| 31 | Как играть | открывает `elytrix:duel_help` |
| 45 | Главное меню | возврат в `/menu` |
| 49 | Закрыть | закрывает меню, `red_dye` |

### Очередь (`elytrix:duel_queue`)

10 китов: `sword`, `uhc`, `gapple`, `sumo`, `archer`, `mace`, `axe`,
`trident`, `crossbow`, `netherite`. Клик → `/duel queue <кит>` и меню
закрывается. Наборы создаёт мост при запуске (см. `КИТЫ.md`).

**Важно:** имена китов должны совпадать с тем, что создано в EpicDuels
(`/duel kit create sword` и т.д.). Если назовёшь иначе — поправь
`[player] duel queue <имя>` у нужной кнопки в `queue.yml`.

Киты стоят в слотах `20`–`24` и `29`–`33`, выход из очереди — `40`,
внизу `45` — назад, `49` — закрыть.

### Бои 2 на 2

Кнопка в слоте `21` → своё окно выбора напарника → выбор кита → кнопка
«Встать в очередь». Пара ждёт вторую пару с тем же китом, затем мост
запускает бой 4 игроков и сам расставляет команды. Кнопки «Группа» и
отдельных групповых окон (`duel_party`, `duel_party_size`) больше нет.
Наблюдение убрано: в `EpicDuels/config.yml` стоит `features.spectating: false`.

### Статистика (`elytrix:duel_stats`)

Победы, поражения, процент, очки, топ и кнопка «Сыграть». Значения
подставляются без PlaceholderAPI: мост передаёт их в BMenu как
`{wins}`, `{losses}`, `{winrate}`, `{score}`.

### Раунды (`elytrix:duel_rounds`)

1 / 3 / 5 раундов → `/duelx rounds N`, дальше плагин сам показывает выбор карты.

### Инструкция (`elytrix:duel_help`)

Четыре шага: режим → кит → карта и раунды → бой. Плюс блок «Важно»:
наград нет, инвентарь не трогается, выход из боя = поражение.

## Анимация

Как в главном меню: сначала появляются служебные кнопки (закрыть/назад),
потом по спирали собирается фиолетовая рамка, затем чёрные панели и по
очереди кнопки. Звуки — `block.enchantment_table.use` на старте,
`note_block.chime` на рамке (тон растёт), `note_block.pling` на кнопках,
`amethyst_block.chime` на финале.

Если нужно тише — правь второе число у `sound:` (громкость).
Если нужно быстрее — удаляй кадры рамки, а не кнопок.

## Кнопка в главном меню

Чтобы игроки попадали в дуэли из `/menu`, в `BMenu/menu/elytrix/main/menu.yml`
добавь предмет:

```
  duels:
    material: netherite_sword
    name: '&7« &#F8BEFBДуэли &7»'
    lore:
    - '&#F8BEFB&l┃ '
    - '&#F8BEFB&l┃ &fФормат: &#F8BEFB1 на 1 и команды'
    - '&#F8BEFB&l┃ &fКиты: &#F8BEFB9 готовых'
    - '&#F8BEFB&l┃ '
    - '&7● &fНажмите, чтобы открыть'
    on_click:
    - sound: 'block.note_block.pling 0.4 1.2'
    - '[open] elytrix:duel'
```

И добавь его в `animation:` на свободный слот (например `st: duels 25`).
Файл `main/menu.yml` я не менял — по твоему указанию.

## Выбор соперника — своё окно

Окно `DUELS` из EpicDuels больше не показывается: мост рисует своё —
головы онлайн-игроков, по 28 на страницу, кнопки «назад/вперёд/закрыть»,
у занятых в бою подписано «сейчас в бою». Клик сразу открывает выбор кита.

Плюс быстрый вызов: **`/duel ник`** (и `/d ник`) — сразу меню кита, без
списка и без команд плагина.

## Быстрые 2 на 2 (очередь пар)

1. «Бои 2 на 2» → выбираешь напарника (он сразу в группе, никаких
   `/party invite` и подтверждений).
2. Выбираешь кит → «Встать в очередь».
3. Когда вторая пара с тем же китом встаёт в очередь — бой стартует сам.

EpicDuels при старте командного боя перемешивает игроков и делит пополам,
поэтому мост сразу после старта выставляет составы обратно: твоя пара
против второй пары. Если в группе больше двух человек, команды делятся
как раньше — случайно.

## Статистика без PlaceholderAPI

Значения передаются прямо в меню BMenu (`{wins}`, `{losses}`,
`{winrate}`, `{score}`), поэтому проценты не зависят от установленного
расширения PAPI: даже если стоит оригинальный EpicDuels без расширения,
цифры будут.

## Мост `ElytrixDuelsBridge`

Мост слушает `InventoryOpenEvent`: если EpicDuels собирается открыть своё
окно, окно отменяется и через тик открывается меню BMenu. Соответствие
задаётся в `plugins/ElytrixDuelsBridge/config.yml`:

| Окно EpicDuels | Меню BMenu |
|---|---|
| `MAIN` | `elytrix:duel` |
| `STATS` | `elytrix:duel_stats` |
| `MATCHMAKING` | `elytrix:duel_queue` |
| `KIT_SELECT` | `elytrix:duel_kit` |
| `PARTY_KIT` | `elytrix:duel_kit` |
| `PARTY_CONFIRM` | `elytrix:duel_confirm` |
| `ROUNDS_SELECT` | `elytrix:duel_rounds` |

Остаются за плагином только окна с «живым» содержимым: арены
(`ARENA_SELECT`). Список игроков рисует сам мост (своё окно с головами),
наблюдение отключено в конфиге EpicDuels. Окна плагина перекрашены через
`menus.yml` EpicDuels.

Кнопки новых меню вызывают `/duelx`:

```
/duelx rounds <1|3|5>            передать раунды и открыть выбор карты
/duelx target <ник>              соперник выбран → меню кита
/duelx team                      выбор напарника (быстрый 2 на 2)
/duelx kit <кит>                 выбранный кит → раунды или подтверждение
/duelx confirm | cancel          начать бой / встать в очередь / отмена
/duelx open <menu>               открыть меню BMenu по id
```

`/duelx` дергает публичные методы `GUIManager` — то же, что делает клик в
окне плагина, — и проверяет то же, что плагин: включены ли `team-duels` и
`tournaments`, есть ли готовые арены. Ошибки не ломают меню: игрок видит
понятное сообщение в чате.

## Ограничения EpicDuels

- `/duel challenge` и `/duel duels` открывают окно выбора игрока — его
  заменяет наше окно с головами. Дальше кит, раунды и карта идут через
  меню моста; окно выбора арены остаётся за EpicDuels.
- Рамки внутри окон плагина рисует сам плагин, их цвет конфигом не меняется.
- Профиль в главном меню показывает цифры без PlaceholderAPI: мост
  передаёт значения в BMenu при открытии.
