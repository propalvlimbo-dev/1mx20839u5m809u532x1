# Меню дуэлей в BMenu (стиль ElytriX)

Своё меню поверх EpicDuels: те же рамки, звуки и анимация сборки, что в
главном меню сервера. Игрок видит кнопки с объяснением, а не английское GUI.

## Что в комплекте

```
plugins/BMenu/menu/elytrix/duel/
├── duel.yml         главное меню дуэлей
├── queue.yml        выбор кита для очереди
├── help.yml         «Как играть», 4 шага
├── stats.yml        профиль и топ
├── rounds.yml       число раундов: 1 / 3 / 5
├── kit.yml          выбор кита (те же 9 китов, что в queue.yml)
└── confirm.yml      подтверждение боя / постановка пары в очередь
```

Плюс мост `ElytrixDuelsBridge-1.11.0.jar`: он подменяет окна самого
EpicDuels на эти меню и рисует своё окно выбора игрока. Без моста `/duel` показывает меню плагина
(перекрашенное, но без анимации BMenu).

`BMenu/config.yml` — добавлены команды открытия:

```
/duels        (/дуэли)
/duelshelp    (/дуэлипомощь)
```

## Установка

1. Скопировать папку `elytrix/duel` в `plugins/BMenu/menu/elytrix/`.
2. В `plugins/BMenu/config.yml` в `open_commands` добавить блок:

```
  duels:
    menu: elytrix:duel
    aliases:
      - duels
      - дуэли
  duel_help_menu:
    menu: elytrix:duel_help
    aliases:
      - duelshelp
      - дуэлипомощь
```

3. Положить `ElytrixDuelsBridge-1.11.0.jar` в `plugins/` (нужны `EpicDuels`
   и `BMenu`).
4. Перезагрузить сервер.
5. Проверить: `/duel` — должно открыться наше меню с анимацией.
6. `/duelx kits reset` — киты 3.0 (полные сеты, зелья, лук/арбалет); обычно накатываются сами.
   Состав правится в игре: `/duelx kit edit <кит>` или `/duelx kit save <кит>`.

Топы для сайта мост пишет сам: `plugins/ElytrixDuelsBridge/tops.json`.
Для кода — `ru.elytrix.duelsbridge.TopsApi.topByWins(10)`.

## Что делает каждая кнопка

### Главное меню (`elytrix:duel`)

| Слот | Кнопка | Действие |
|---|---|---|
| 4 | Твой профиль | открывает статистику (`duelx stats`) |
| 20 | Дуэль 1 на 1 | `/duelx pick` — выбор игрока |
| 21 | Бои 2 на 2 | выбор напарника → он подтверждает → кит → очередь |
| 22 | Поиск соперника | меню с китами → сразу очередь 1 на 1 |
| 23 | Статистика | `duelx stats` — цифры подставляет мост |
| 24 | Рейтинг | `/duel leaderboard wins` |
| 31 | Как играть | открывает `elytrix:duel_help` |
| 45 | Главное меню | возврат в `/menu` |
| 49 | Закрыть | закрывает меню, `red_dye` |

### Очередь (`elytrix:duel_queue`)

10 китов: `Классика`, `УХК`, `Гаппли`, `Сумо`, `Лучник`, `Булава`,
`Топор`, `Тризуб`, `Арбалет`, `Незерит`. Клик → `/duelx queue <кит>`,
меню закрывается, мост сам ищет соперника с тем же китом. Наборы создаёт
мост при запуске (см. `КИТЫ.md`).

Киты — это id в `kits.yml` EpicDuels. Старые английские id (`sword`, `uhc`…)
по-прежнему принимаются как синонимы.

Киты стоят в слотах `20`–`24` и `29`–`33`, выход из очереди — `40`,
внизу `45` — назад, `49` — закрыть.

### Поиск боя (`elytrix:duel_queue_wait`)

Пока игрок в очереди, `/duel` открывает это окно: одна красная кнопка
«Отменить поиск» и описание — режим, кит, сколько уже ждём. Закрыть окно
можно спокойно: поиск продолжится, а строка `Поиск » кит · 1:24` останется
внизу экрана.

### Бои 2 на 2

Кнопка в слоте `21` → окно выбора напарника:

- клик по голове — приглашение, напарник получает в чате **[Принять]** и
  **[Отклонить]** (кнопки отправляют `/duel team accept <ник>`, поэтому
  ванильного «нераспознанная команда» нет); приглашение живёт 60 секунд;
- `Случайный тиммейт` — приглашение уходит случайному свободному игроку;
- `Рандом без тиммейта` — встаём в очередь 2 на 2 одни, напарника мост
  подберёт из таких же одиночек.

После согласия оба выбирают кит (кит выбирает тот, кто позвал) и пара
встаёт в очередь. Две пары с одним китом встречаются автоматически.
Если пар мало, пара может сыграть против двух одиночек — мост сведёт их
в одну команду. Кнопки «Группа» и окон `duel_party*` больше нет,
наблюдение выключено (`features.spectating: false`).

### Статистика (`elytrix:duel_stats`)

Победы, поражения, процент, очки, топ и кнопка «Сыграть». Мост передаёт
цифры в BMenu как `{wins}`, `{losses}`, `{winrate}`, `{score}` — без
PlaceholderAPI.

**Почему были видны `{wins}`:** BMenu открывает меню с готовыми значениями
только когда его открывает мост. Любая кнопка `[open]` внутри BMenu
(например, из общего `/menu`) открывает меню «пустым», и скобки оставались
как текст. Сейчас:

- в `stats.yml` прописаны значения по умолчанию (`args:`), поэтому вместо
  `{wins}` максимум будет `0`;
- все кнопки статистики идут командой `/duelx stats` — мост передаёт цифры
  через API BMenu и сам проверяет, что они подставились;
- если версия BMenu не принимает значения, мост пишет цифры строкой в чат
  («Победы: 5 · Поражения: 2 · Побед: 71.4% · Очки: 12») и предупреждение
  в консоль. Подробный лог — `menus.debug: true`.

### Раунды (`elytrix:duel_rounds`)

1 / 3 / 5 раундов → `/duelx rounds N`, дальше вызов сразу уходит сопернику:
карту выбирать не нужно, берётся случайная готовая арена.

### Инструкция (`elytrix:duel_help`)

Четыре шага: режим → кит → раунды → бой (карта случайная). Плюс блок «Важно»:
наград нет, инвентарь не трогается, выход из боя = поражение.

## Анимация

Как в главном меню: сначала появляются служебные кнопки (закрыть/назад),
потом по спирали собирается фиолетовая рамка, затем чёрные панели и по
очереди кнопки. Звуки — `block.enchantment_table.use` на старте,
`note_block.chime` на рамке (тон растёт), `note_block.pling` на кнопках,
`amethyst_block.chime` на финале.

Если нужно тише — правь второе число у `sound:` (громкость).
Если нужно быстрее — удаляй кадры рамки, а не кнопок.

## Кнопка в главном меню

Чтобы игроки попадали в дуэли из `/menu`, в `BMenu/menu/elytrix/main/menu.yml`
добавь предмет:

```
  duels:
    material: netherite_sword
    name: '&7« &#F8BEFBДуэли &7»'
    lore:
    - '&#F8BEFB&l┃ '
    - '&#F8BEFB&l┃ &fФормат: &#F8BEFB1 на 1 и команды'
    - '&#F8BEFB&l┃ &fКиты: &#F8BEFB9 готовых'
    - '&#F8BEFB&l┃ '
    - '&7● &fНажмите, чтобы открыть'
    on_click:
    - sound: 'block.note_block.pling 0.4 1.2'
    - '[open] elytrix:duel'
```

И добавь его в `animation:` на свободный слот (например `st: duels 25`).
Файл `main/menu.yml` я не менял — по твоему указанию.

## Команды для игрока

```
/duel            главное меню дуэлей
/duel ник        сразу выбор кита для вызова
```

Всё остальное — кнопки в меню. Таб-дополнение после `/duel ` показывает ники
онлайн-игроков. Подкоманды EpicDuels (`arena`, `kit`, `queue`, `stats`,
`leaderboard`) обычному игроку недоступны; админам — без изменений.

Скрыть команды сервера от игроков (замена PLHide) можно там же, в
`ElytrixDuelsBridge/config.yml`, раздел `command-guard`.

## Выбор соперника — своё окно

Окно `DUELS` из EpicDuels больше не показывается: мост рисует своё —
головы онлайн-игроков, по 28 на страницу, кнопки «назад/вперёд/закрыть»,
у занятых в бою подписано «сейчас в бою». Клик сразу открывает выбор кита.

Плюс быстрый вызов: **`/duel ник`** (и `/d ник`) — сразу меню кита, без
списка и без команд плагина.

## Быстрые 2 на 2 (очередь пар)

1. «Бои 2 на 2» → выбираешь напарника → **он подтверждает** приглашение.
2. Выбираешь кит → пара встаёт в очередь.
3. Когда вторая пара с тем же китом встаёт в очередь — бой стартует сам.

Сроки: приглашение — 60 секунд, поиск 2 на 2 — 5 минут, поиск 1 на 1 —
3 минуты (меняется в `queue.*` конфига моста). Пара живёт, пока не
начался бой, пока кто-то не вышел `/duelx team leave` или не покинул
сервер.

EpicDuels при старте командного боя перемешивает игроков и делит пополам,
поэтому мост сразу после старта выставляет составы обратно: твоя пара
против второй пары. Одиночек мост тоже сводит в пару сам.

## Статистика без PlaceholderAPI

Значения передаются прямо в меню BMenu (`{wins}`, `{losses}`,
`{winrate}`, `{score}`) при открытии через мост (`/duelx stats`, кнопки
меню). PAPI не нужен. Если открыть `elytrix:duel_stats` вручную командой
`/bmenu open`, чисел не будет — BMenu не знает, чьи они.

## Мост `ElytrixDuelsBridge`

Мост слушает `InventoryOpenEvent`: если EpicDuels собирается открыть своё
окно, окно отменяется и через тик открывается меню BMenu. Соответствие
задаётся в `plugins/ElytrixDuelsBridge/config.yml`:

| Окно EpicDuels | Меню BMenu |
|---|---|
| `MAIN` | `elytrix:duel` |
| `STATS` | `elytrix:duel_stats` |
| `MATCHMAKING` | `elytrix:duel_queue` |
| `KIT_SELECT` | `elytrix:duel_kit` |
| `PARTY_KIT` | `elytrix:duel_kit` |
| `PARTY_CONFIRM` | `elytrix:duel_confirm` |
| `ROUNDS_SELECT` | `elytrix:duel_rounds` |

Остаются за плагином только окна с «живым» содержимым: арены
(`ARENA_SELECT`). Список игроков рисует сам мост (своё окно с головами),
наблюдение отключено в конфиге EpicDuels. Окна плагина перекрашены через
`menus.yml` EpicDuels.

Кнопки новых меню вызывают `/duelx`:

```
/duelx pick                      своё окно выбора игрока
/duelx queue <кит|leave>         очередь / выход из очереди
/duelx top                       таблица лидеров
/duelx rounds <1|3|5>            передать раунды → вызов на случайную арену
/duelx target <ник>              соперник выбран → меню кита
/duelx team                      выбор напарника (быстрый 2 на 2)
/duelx kit <кит>                 выбранный кит → раунды или подтверждение
/duelx confirm | cancel          начать бой / встать в очередь / отмена
/duelx open <menu>               открыть меню BMenu по id
```

`/duelx` дергает публичные методы `GUIManager` — то же, что делает клик в
окне плагина, — и проверяет то же, что плагин: включены ли `team-duels` и
`tournaments`, есть ли готовые арены. Ошибки не ломают меню: игрок видит
понятное сообщение в чате.

## Ограничения EpicDuels

- Игроку доступны только `/duel` и `/duel ник`; подкоманды EpicDuels для
  него закрыты (кроме кнопок в чате: accept, deny, forfeit, rematch).
  Админы видят полный `/duel`.
- Выбор карты убран: после раундов мост сам берёт случайную готовую арену.
- Рамки внутри окон плагина рисует сам плагин, их цвет конфигом не меняется.
- Профиль в главном меню показывает цифры без PlaceholderAPI: мост
  передаёт значения в BMenu при открытии.
