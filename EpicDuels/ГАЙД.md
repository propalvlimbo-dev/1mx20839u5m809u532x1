# EpicDuels 3.1 — гайд (ElytriX)

## Что в архиве

```
EpicDuels-ElytriX/
├── ГАЙД.md                      ← этот файл
├── plugins/
│   ├── EpicDuels-3.1.0.jar      ← сам плагин
│   └── EpicDuels/               ← готовая настроенная папка
│       ├── config.yml           ← русский язык, награды, лобби
│       ├── menus.yml            ← заголовки и кнопки в стиле ElytriX
│       ├── scoreboard.yml       ← скорборд дуэли/наблюдения/очереди
│       └── lang/messages_ru.yml ← 288 строк перевода
├── АРЕНЫ.md                     ← как перенести арены из мира duel
└── КИТЫ.md                      ← 10 готовых китов для сборки
```

Содержимое `plugins/` кидается в `plugins/` сервера — пути уже совпадают.

## Установка (5 минут)

1. **Остановить сервер.**
2. Скопировать `plugins/EpicDuels-3.1.0.jar` и папку `plugins/EpicDuels/`
   в `plugins/` сервера.
3. **Запустить сервер.**
4. Зайти админом на спавн и выполнить:

```
/duel setlobby
```

Без этого после дуэли игроков будет кидать в `0 100 0` мира `spawn`.

5. Проверить: `/duel` — должно открыться меню с русскими кнопками.

Всё. Арены и киты добавляются отдельно (ниже).

## Что настроено под сервер

Плагин по умолчанию рассчитан на отдельный дуэльный сервер, где «лобби» —
это весь мир. У нас выживание + гриф, поэтому:

| Что | Как стоит | Зачем |
|---|---|---|
| `language` | `ru` | русский |
| `lobby.handle-join` | `false` | иначе при каждом входе чистится инвентарь и кидает в лобби |
| `lobby.disable-pvp` | `false` | иначе PvP отключается во всех мирах, кроме арен |
| `lobby.protections.*` | всё `false` | иначе нельзя ломать, ставить, подбирать, есть |
| `duel.countdown-seconds` | `3` | быстрый старт |
| `duel.time-limit-seconds` | `300` | 5 минут на бой |
| `features.own-inventory-duels` | `false` | играют только готовыми китами |
| `features.kit-editor` | `false` | игроки не собирают и не правят киты |
| `stats.backend` | `local` | без Supabase/Firebase |

Награды (`result-commands`, консольные команды):

```
победитель: points give {player} 25   +   eco give {player} 500
проигравший: points give {player} 5
```

`points` — PlayerPoints, `eco` — EssentialsX/Vault. Если у тебя другие
названия — править здесь и `/duel reload`.

## Арены (важно)

EpicDuels **не играет в готовом мире** `duel`. Он для каждого боя копирует
маленький мир-шаблон `arena_template_<имя>` в `arena_instance_<номер>`.
Поэтому арены из `duel` переносятся один раз:

```
1. в мире duel у арены:  //pos1  //pos2  →  //copy
2. /duel arena create arena1        (создаст и телепортирует в шаблон)
3. //paste
4. /duel arena setspawn1   (встать в точку спавна игрока 1)
5. /duel arena setspawn2   (точка спавна игрока 2)
6. /duel arena save arena1
```

Повторить для каждой арены. Хватит 6: `arena1..3`, `nether`, `desert`, `crystal`.
Подробно — `АРЕНЫ.md`.

## Киты

Игроки киты не собирают и не правят — только выбирают из готовых.
Создаёт киты админ, один раз:

```
1. /gamemode creative
2. собрать предметы
3. /duel kit create sword
4. взять предмет в руку → /duel kit seticon sword
```

Готовые наборы (sword, nodebuff, uhc, sumo, gapple, archer, mace, crystal,
pot, own) расписаны по слотам в `КИТЫ.md` — только предметы 1.21.4,
чтобы клиенты 1.21.4 видели всё без ошибок.

## Команды

```
/duel                     меню
/duel challenge <ник>     вызвать
/duel queue <кит>         очередь
/duel spectate            смотреть бои
/duel stats [ник]         статистика
/duel kits                своя раскладка китов
/duel forfeit             сдаться
/duel rematch             реванш
/duel leaderboard wins|score
/duel setlobby            точка лобби (админ)
/duel reload              перечитать конфиг (админ)
/duel arena ...           арены (админ)
/duel kit ...             киты (админ)
/party ...                группы 2v2–4v4 и турниры
```

Псевдонимы: `/d`, `/p`. Права по умолчанию уже стоят: игрокам — `duel`,
`stats`, `party`, `spectate`, админам — `epicduels.admin`.

## В меню

Главное меню (27 слотов) — 4 кнопки, пятая (раскладка китов) отключена:

| Слот | Кнопка | Что делает |
|---|---|---|
| 4 | Наблюдение | смотреть живые бои |
| 10 | Дуэль | выбрать игрока и вызвать |
| 13 | Статистика | победы и поражения |
| 16 | Поиск соперника | очередь по киту |

Оформление:

- заголовки `#F8BEFB` жирным;
- лор: `┃` — данные, `●` — действие;
- навигация: `black_dye` — назад/далее, `red_dye` — закрыть, стрелок нет;
- игрок в меню видит только готовые киты — собрать свой нельзя.

Меню, где предметы создаёт сам плагин (список игроков, китов, карт,
наблюдение, поиск соперника), перекрашены в `menus.yml` по слотам
`10–43`. Числа в статистике и размер группы плагин подставляет сам —
шаблоном их не заменить.

## Интеграции

- **BMenu:** кнопка в главном меню — `[player] duel`.
- **PlaceholderAPI:** `%epicduels_wins%`, `%epicduels_losses%`,
  `%epicduels_winrate%`, `%epicduels_score%`, `%epicduels_in_duel%`.
- **TAB / скорборд:** `Дуэли: %epicduels_wins% побед | %epicduels_winrate%%`
- **Голограммы:** `/duel leaderboard sethologram wins`.

## Если не работает

| Симптом | Причина |
|---|---|
| кидает в `0 100 0` | не выполнен `/duel setlobby` |
| пустой инвентарь после входа | `lobby.handle-join: true` |
| нет PvP в мире | `lobby.disable-pvp: true` |
| нельзя ломать блоки | включён один из `lobby.protections.*` |
| «No arenas available» | нет арен или у арены нет двух точек спавна |
| меню на английском | нет `lang/messages_ru.yml` или `language: en` |
| киты выглядят иначе на 1.21.4 | в ките предмет новее 1.21.4 |
