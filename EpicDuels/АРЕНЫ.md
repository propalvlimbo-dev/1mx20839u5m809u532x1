# Арены: все в одном мире `duel`

Нужен `EpicDuels-ElyTriX-3.1.1.jar` (наш форк) и мост `ElytrixDuelsBridge-1.7.0.jar`.
Мир `duel` у тебя уже есть — новые миры создавать не нужно.

## Как это работает

Обычный EpicDuels требует по миру на арену (`arena_template_<имя>`), потому что
имя мира выводится из имени арены. В нашем билде у арены появился **общий мир**:
мост вызывает `Arena.setDefaultWorld("duel")`, и все арены живут в мире `duel`,
отличаясь только точками спавна.

На каждый бой EpicDuels всё так же копирует мир `duel` в
`arena_instance_<номер>` — поэтому бойцы не мешают друг другу и не ломают мир,
а число арен не ограничено четырьмя: одновременно может идти сколько угодно
боёв, у каждого своя копия.

## Настройка

`plugins/ElytrixDuelsBridge/config.yml`:

```yaml
arenas:
  world: "duel"      # пусто — вернуть старое поведение (по миру на арену)
```

Дальше всё делается стоя в мире `duel`, без телепортов по шаблонам:

```
/duelx arena create arena1     # завести арену
/duelx arena spawn1 arena1     # встать в точку первой команды и выполнить
/duelx arena spawn2 arena1     # встать в точку второй команды
/duelx arena ready arena1      # включить в ротацию
```

Повтори для `arena2` … `arena6` — столько арен, сколько нужно. Проверить:

```
/duelx arena list              # кто готов, у кого нет точек
/duelx arena tp arena1         # прыгнуть на первую точку
/duelx arena remove arena2     # убрать арену (сам мир duel не трогается)
```

Права: команды доступны администратору (`epicduels.admin`, `elytrix.guard.bypass` или OP).

## 2 на 2

Отдельные точки для 2 на 2 не нужны: `spawn1` и `spawn2` — это точки
**команд**, а напарники встают рядом с ними (EpicDuels сам расставляет их
вокруг точки). Если хочется, чтобы четвёрка стояла шире — сделай точки
чуть дальше друг от друга.

## Что важно знать

- `setspawn` в самом EpicDuels (`/duel arena setspawn1`) работает только в
  мире `arena_template_*`, поэтому в режиме общего мира пользуйся
  `/duelx arena spawn1 <имя>`.
- Мир `duel` при первом создании арены получает настройки EpicDuels:
  без мобов, без смены дня и погоды, время 6000. Это нормально для арен.
- Границы боя считаются по точкам спавна (`protection.arena-margin`), так что
  арены в одном мире не мешают друг другу. Проверить в бою: `/duelx bounds`.
- Если вернуть `arenas.world: ""`, EpicDuels снова будет искать
  `arena_template_<имя>` — старый режим никуда не делся.

## Старый режим (по миру на арену)

```
/duel arena create arena1    # создаёт мир arena_template_arena1 и телепортирует туда
//paste                       # вставить скопированную арену (FAWE)
/duel arena setspawn1
/duel arena setspawn2
/duel arena save arena1
```

`/duel arena list` · `/duel arena tp` · `/duel arena seticon` ·
`/duel arena rename` · `/duel arena delete` — работают как раньше.
