# Арены EpicDuels и уже построенный мир `duel`

## Коротко: только команды (карта уже есть)

Скопировал арену из `duel` (FAWE: `//pos1`, `//pos2`, `//copy`) — дальше:

```
/duel arena create arena1    # создаёт мир arena_template_arena1 и телепортирует туда
//paste                       # вставить скопированную арену в шаблон
/duel arena setspawn1        # встать в точку появления первого игрока
/duel arena setspawn2        # вторая точка появления
/duel arena save arena1      # арена готова — мост берёт её случайно
```

Дополнительно:

```
/duel arena list             # все арены: готовые и недоделанные
/duel arena tp arena1        # вернуться в шаблон арены
/duel arena seticon arena1   # иконка в меню: предмет в руке
/duel arena rename arena1 pvp1
/duel arena delete arena1
```

Имя арены — только латиница, цифры, `_` и `-`. `setspawn1`/`setspawn2`
работают **только внутри мира `arena_template_<имя>`**: команда сама
понимает, к какой арене ты стоишь.

На боевых копиях арены (`arena_instance_*`) мост запрещает ставить блоки и
выливать жидкости, а взрывы не ломают ни одного блока. В шаблоне
(`arena_template_*`) строительство остаётся, там ты собираешь арену.

## Главное, что нужно знать

EpicDuels **не берёт арены из готового мира**. На каждый бой он:

1. берёт папку мира-шаблона `arena_template_<имя>`;
2. копирует её в `arena_instance_<номер>`;
3. загружает копию как отдельный мир, проводит бой;
4. удаляет мир и папку.

Поэтому арене нужен **свой маленький мир**, а не точка в общем `duel`.
Если прописать в `arenas.yml` мир `duel`, плагин начнёт копировать весь
`duel` целиком на каждый бой — это сотни мегабайт и секунды ожидания.

Значит: арены из `duel` **один раз** переносятся в шаблоны. Дальше они
работают сами, а `duel` остаётся как обычный мир (PvP там не ломается).

## Перенос одной арены (5 минут)

Нужны права `epicduels.admin` и FAWE (у нас есть).

```
1. В мире duel встать у арены и выделить её:
   //pos1  //pos2     (или //wand)
   //copy

2. Создать шаблон:
   /duel arena create arena1
   — плагин создаст мир arena_template_arena1 и телепортирует туда

3. Встать в точку, где должен быть угол арены, и вставить:
   //paste

4. Поставить точки спавна игроков (там, где они появляются):
   встать на первую точку  → /duel arena setspawn1
   встать на вторую точку  → /duel arena setspawn2

5. Сохранить:
   /duel arena save arena1
```

После `save` арена готова, тебя вернёт в лобби.

## Выбора карты у игроков нет

Мост сам берёт случайную готовую арену, поэтому:
- все арены должны быть готовы (`/duel arena list` — статус `ready`);
- если готовых нет, игрок получит «Нет готовых арен»;
- минимально нужна одна, для параллельных боёв — по одной на бой.

## Если арена уже построена в готовом мире

EpicDuels не умеет брать арену по координатам из общего мира: арена `X` —
это всегда папка мира `arena_template_X` в корне сервера (жёстко зашито,
в конфиге не меняется). Поэтому есть два пути.

### Путь 1 — вырезать арену (рекомендую)

Как в инструкции выше: `/duel arena create`, `//paste` из `duel`,
`setspawn1/2`, `save`. Копия мира содержит только арену, бои стартуют быстро.

### Путь 2 — взять готовый мир целиком

Если мир уже и есть одна арена (или так проще):

```
1. Остановить сервер (обязательно: регионы должны быть сброшены на диск)
2. Скопировать папку мира:  world/duel  →  world/arena_template_arena1
   (в корне сервера, рядом с world, world_nether)
3. Запустить сервер
4. /duel arena tp arena1     — проверить, что мир открылся
5. встать на точки появления → /duel arena setspawn1 / setspawn2
6. /duel arena save arena1
```

Что важно знать про путь 2:

- папку копируй **при выключенном сервере**, иначе часть чанков не доедет;
- папки `DIM-1` и `DIM1` (ад и энд) в копии не нужны — можно удалить;
- на каждый бой копируется **весь** мир целиком: чем он больше, тем дольше
  старт и больше нагрузка на диск. Арена на 2–3 чанка — нормально,
  мир на 500 МБ — нет;
- имя папки должно совпадать с ареной: `arena_template_<имя>`.

### Несколько арен в одном мире

Так нельзя: одна арена = один мир. Варианты:

1. Вырезать каждую арену FAWE в свой шаблон (путь 1) — правильный вариант.
2. Сделать N копий мира и в каждой поставить спавны на свою арену. Работает,
   но каждый бой копирует весь мир — годится только для маленького мира.

## Имена и иконки

Имя арены — только латиница, цифры, `_` и `-`. Имя = `arena1`, `nether`,
`desert`, `crystal` и т.д.

Иконка в меню: взять предмет в руку →

```
/duel arena seticon desert
```

## Полезное

```
/duel arena list              — все арены и готовность
/duel arena tp desert         — прыгнуть в шаблон
/duel arena create <имя>      — новая (пустая) арена
/duel arena delete <имя>      — удалить вместе с миром
/duel arena rename <a> <b>    — переименовать
```

## Сколько арен нужно

Минимум — 6, чтобы в меню было из чего выбрать и чтобы двое боёв
одновременно не делили карту:

`arena1`, `arena2`, `arena3`, `nether`, `desert`, `crystal`

Правила:

- в шаблоне только сама арена, без декораций вокруг на 200 блоков;
- всё, что игрок может сломать, плагин восстановит после раунда;
- жидкости из ведра отслеживаются, оригинальные — нет;
- чем меньше мир, тем быстрее копирование.

## Если не хочется переносить

Оставить арены в `duel` и играть там можно только другим плагином
(Duels Optimised умеет работать с готовыми аренами + WorldGuard).
EpicDuels такой режим не поддерживает.
