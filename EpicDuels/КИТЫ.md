# Киты EpicDuels — быстрый сбор

Кит = снимок инвентаря. Порядок один:

```
1. /gamemode creative
2. выдать себе предметы (/give)
3. разложить по хотбару, броне и левой руке
4. /duel kit create <имя>
```

Всё, что лежит в инвентаре (36 слотов + 4 брони + левая рука), попадёт в кит.
Лишнее — выкинуть до создания.

Зачарования: взять предмет в руку и `/enchant minecraft:<чар> <уровень>`
(на 1.21.4+ зачарование `minecraft:` обязательно).

Иконка кита в меню: взять предмет в руку → `/duel kit seticon <имя>`.

Киты собраны только из предметов, которые есть в 1.21.4, поэтому клиенты
1.21.4–1.21.11 видят всё одинаково.

## 10. own — свой инвентарь

Отдельный кит не нужен: в меню выбора кита уже есть пункт
«Свой инвентарь» (`own-inventory-duels: true`). Инвентарь сохраняется
и возвращается после дуэли, даже если сервер упал.

## Проверка

1. `/duel kit list` — все киты на месте.
2. `/duel kit give <кит>` — выдать себе и посмотреть.
3. `/duel kit seticon <кит>` — иконка в меню.
4. Зайти клиентом 1.21.4 и открыть выбор кита — предметы должны
   отображаться без ошибок.
