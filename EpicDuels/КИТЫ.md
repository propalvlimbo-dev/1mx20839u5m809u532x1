# Киты EpicDuels — 10 готовых наборов

Наборы создаёт сам мост `ElytrixDuelsBridge` при запуске сервера: он вызывает
`KitManager#createKit` и сохраняет `plugins/EpicDuels/kits.yml`. Вручную
собирать ничего не нужно.

- имена китов русские: их видно и в меню, и в сообщениях, и на скорборде;
- старые английские id (`sword`, `uhc`, ...) при первом запуске переносятся
  под русские имена вместе с содержимым;
- существующие киты не перезаписываются;
- пересоздать все десять: `/duelx kits reset` (нужно право на команду `/duelx`);
- отключить автосоздание: `kits.auto-install: false` в
  `plugins/ElytrixDuelsBridge/config.yml`.

Все наборы работают **без установки блоков** — на аренах ставить блоки
нельзя. Поэтому в списке нет «кристаллов» и других китов с обсидианом.

Киты 3.0 — полноценные наборы топ-уровня: незерит/алмаз с защитой 3–4,
острота 4–5, тотемы, зелья силы/скорости/регена/огнестойкости. Лук или
арбалет есть у всех, кроме `Сумо` (там бой только на отбрасывание).
Зелья выдаются предметами с эффектами — пьются как обычные, ничего
дополнительно ставить не нужно.

Перки выдаёт мост, а не EpicDuels: эффекты появляются при входе на боевую
копию арены и снимаются после боя. Меняются в `config.yml` моста, раздел
`buffs.per-kit` (см. `ElytrixDuelsBridge/README.md`).

Новый состав накатывается сам один раз: в `config.yml` моста есть
`kits.revision: 3`, и при несовпадении киты пересоздаются при запуске.
Пересоздать вручную — `/duelx kits reset`, один кит — `/duelx kit reset <кит>`.

Имя кита — это его id: `duelx kit Классика`, `duelx queue Классика`.
Прежние английские id тоже принимаются (`duelx kit sword` = `Классика`),
поэтому старые меню и команды не ломаются.

## Редактор наборов

Полный редактор — родной GUI EpicDuels, открывается из моста:

```
/duelx kit edit            # список китов в GUI
/duelx kit edit Классика   # редактор одного кита: тащи предметы, кнопка «Save Kit»
```

Команды (только администратор):

```
/duelx kit save <кит>              # сохранить набор из своего инвентаря (36 слотов + броня + левая рука)
/duelx kit list                    # все киты и сколько в них предметов
/duelx kit reset <кит>             # вернуть стандартный состав
/duelx kit rename <старое> <новое>
/duelx kit delete <кит>
/duelx kit icon <кит>              # иконка — предмет в руке
/duelx kits reset                  # пересоздать все десять
```

Удобный порядок: `/duelx kit edit Классика` → раскидать вещи по слотам →
`Save Kit`. Для нового кита проще собрать инвентарь и сделать
`/duelx kit save МойКит`.

## Если хочется поправить кит руками

```
/gamemode creative
# разложить предметы: хотбар, броня, левая рука
/duel kit create <имя>        # новый кит из инвентаря
/duel kit delete <имя>        # удалить
/duel kit seticon <имя>       # иконка — предмет в руке
```

Лишние предметы из инвентаря попадут в кит, поэтому перед созданием
оставь только нужное.

## Совместимость

Все предметы и зачарования есть в 1.21.4+, поэтому клиенты 1.21.4–1.21.11
видят наборы одинаково.
