# Права и слоты аукциона (BAuctionV2)

## Чем BAuctionV2 отличается от BAuction

Да, отличаются — и структурой конфига, и тем, как считается лимит.

| | BAuction (v1, 1.3.3) | BAuctionV2 (1.3) |
|---|---|---|
| Где задано | `boosts:` — список бустов | `slots.select_max` + `slots.add_slots` |
| База без прав | `default-slots: 10` (есть всегда) | **нет**, без прав = 0 слотов |
| Что даёт право | `external-slots: N` | `select_max` — **максимум**, `add_slots` — **сумма** |
| Время продажи | `external-sell-time` в том же бусте | отдельного поля нет |

Итоговый лимит в BAuctionV2 (`SlotsConf.collectSlots`):

```
лимит = max(слоты всех select_max, на которые есть право)
      + сумма(слоты всех add_slots, на которые есть право)
```

Свободные слоты = `лимит − количество своих лотов на аукционе`.
Когда свободных нет — сообщение `slots_limited`: «Достигнут лимит слотов».

## Что прописано сейчас

`BAuctionV2/config.yml` → `slots:` (это же — дефолт из jar):

```yaml
slots:
  select_max:
    - 3 bauc.default
    - 5 bauc.vip
    - 7 bauc.donate
    - 10 auc.boost.squid
  add_slots:
    - 1 bauc.add1
    - 2 bauc.add2
    - 3 bauc.add3
    - 4 bauc.add4
    - 1 auc.boost.rent1
    - 3 auc.boost.rent3
    - 5 auc.boost.rent5
    - 10 auc.boost.rent10
    - 20 auc.boost.rent20
```

| Право | Слотов | Тип |
|---|---|---|
| `bauc.default` | 3 | база (выбирается максимум) |
| `bauc.vip` | 5 | база |
| `bauc.donate` | 7 | база |
| `auc.boost.squid` | 10 | база |
| `bauc.add1`…`bauc.add4` | +1…+4 | надбавка |
| `auc.boost.rent1`…`rent20` | +1…+20 | надбавка (ставится меню аренды) |

Важно: строки прав — **произвольные**, они не обязаны начинаться с `bauc.`.
Их читает только конфиг. `bauc.*` в `plugin.yml` — это `default: op`,
и оно **не** выдаёт `bauc.vip` обычным игрокам.

Ещё: у кого нет ни одного права из `select_max` — у того 0 слотов, даже
если есть `bauc.add2`. Поэтому `bauc.default` должен быть у группы `default`.

## LuckPerms: выдать донатам

```bash
# база для всех
lp group default permission set bauc.default true

# донат-группы (выбирается максимум, поэтому vip перекрывает default)
lp group vip     permission set bauc.vip true       # 5 слотов
lp group premium permission set bauc.donate true    # 7 слотов

# надбавки (складываются с базой)
lp group vip permission set bauc.add2 true          # 5 + 2 = 7
lp group premium permission set bauc.add3 true      # 7 + 3 = 10
```

Проверка:

```bash
lp user Nick permission check bauc.vip
lp user Nick permission info
lp group vip permission list
```

Права применяются мгновенно, перезапуск не нужен: лимит считается на каждое
`/ah sell` заново. `lp sync` нужен только если права выдавались на другом сервере.

## Свой тариф, например 15 слотов

1. Добавить строку в `slots.select_max` (или `add_slots`):

```yaml
slots:
  select_max:
    - 3 bauc.default
    - 5 bauc.vip
    - 7 bauc.donate
    - 15 bauc.legend     # новый тариф
    - 10 auc.boost.squid
```

2. Выдать право:

```bash
lp creategroup legend
lp group legend permission set bauc.legend true
```

3. Применить конфиг: `/aha reload` (команда делает `disable → enable`,
   конфиг перечитывается с диска; меню BMenu тоже перезагружаются).

`/ah reload` (без `a`) — это пользовательская команда, конфиг она не читает.
Полный `stop → start` нужен только если правили не `config.yml`, а jar/зависимости.

## Аренда слотов

Меню `auc_rent:*` (см. `BMenu/menu/bauc/rent/`) выдаёт права
`auc.boost.rent*` через LuckPerms **временно**:

```
lp user %player_name% permission settemp auc.boost.rent5 true <секунды>s
```

Эти же права есть в `add_slots`, поэтому аренда сразу поднимает лимит.
Если LuckPerms не установлен, команда просто не выполнится — аренда
«оплатится», но слотов не прибавит. Проверять: `lp user Nick permission check auc.boost.rent5`.

## Быстрая диагностика

- Игрок не может выставить лот, пишет «Достигнут лимит слотов» →
  `lp user Nick permission check bauc.default` и
  `lp user Nick permission check bauc.vip`; если оба `false` — это и есть причина.
- Выдал право, а слотов не прибавилось → смотреть, в тот ли список добавлено
  (`select_max` берёт максимум, а не сумму: `bauc.default` + `bauc.vip` = 5, не 8).
- Хочешь «база + надбавка» → базу кладёшь в `select_max`, надбавку в `add_slots`.
