# Меню ElytriX для BMenu

Этот каталог — полный набор актуальных меню ElytriX. В поставку включены все связанные страницы, в том числе `events/merchant_event.yml` (`elytrix:merchant_event`) и `help/help_basics.yml` (`elytrix:help_basics`), которые раньше отсутствовали в ZIP-пакете.

## Основные страницы

| Назначение | BMenu ID | Файл |
|---|---|---|
| Главное меню `/menu` | `elytrix:menu` | `main/menu.yml` |
| Помощь | `elytrix:help` | `help/help.yml` |
| Основы игры | `elytrix:help_basics` | `help/help_basics.yml` |
| Способы заработка | `elytrix:help_earnings` | `help/help_earnings.yml` |
| Заглушка скупщика | `elytrix:seller_stub` | `help/seller_stub.yml` |

| Магазин за монеты — заглушка | `elytrix:moneyshop` | `shop/moneyshop.yml` |

| Зарплата | `elytrix:salary_rub` | `salary/rub.yml` |

## Раздел заработка

- `/salary` открывает меню зарплаты; сохранены старые алиасы `/rub` и `/rubsalary`.
- Аукцион открывается командой `/ah`; выставление — `/ah sell <цена>`. Конкретные комиссии и суммы меню не придумывает.
- Убийства мобов приносят монеты, но точные ставки зависят от серверных настроек и здесь не указаны.
- Скупщик ресурсов — только информационная заглушка: товары, цены, продажа и выплаты не настроены.
- Кладбище, данжи и серверные события ведут на соответствующие страницы/команды.
- `/moneyshop` остаётся пустой заглушкой без товаров, покупок и транзакций.
- `/donate` сохранён как декоративный пункт за 1299 ₽; дополнительные товары, привилегии и команды не добавлялись.

## Призрачный торговец

Меню событий описывает только способ взаимодействия и валюту. Торговец должен принимать кастомные Призрачные осколки; товары и цены должны быть заданы администратором, а не придуманы в меню. Для обмена используется ПКМ по NPC.

## Стиль и анимация

Главная, заработок и события оформлены единым набором ElytriX: чёрные/пурпурные стеклянные панели, градиент `#F8BEFB`, акцентное оформление, равномерная сетка предметов и последовательное появление рамки/кнопок. Страницы Ghost Trader используют лавандовый акцент `#B7A8FF`.

## Установка

1. Сделайте резервную копию `plugins/BMenu/menu/elytrix` и `plugins/BMenu/config.yml`.
2. Скопируйте всю папку `menu/elytrix/` из ZIP в `plugins/BMenu/menu/elytrix/`, сохранив подпапки.
3. Объедините команды из `BMenu/config.yml` с действующим конфигом, не заменяя пользовательские настройки BMenu целиком. Для заработка зарегистрирована команда `/salary`; `/rub` и `/rubsalary` оставлены алиасами.
4. Перезапустите/перезагрузите BMenu и проверьте `/menu`, `/help`, `/event`, `/salary`, `/donate` и `/moneyshop`.
