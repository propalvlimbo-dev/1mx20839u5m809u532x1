# Русский перевод FAWE в стиле ElytriX

Полный перевод всех сообщений FastAsyncWorldEdit: 679 ключей, те же ключи и те же
плейсхолдеры `{0}…{5}`, что и в оригинальном `strings.json`.

## Установка

1. Скопировать папки `lang` в `plugins/FastAsyncWorldEdit/`:

```
plugins/FastAsyncWorldEdit/lang/ru/strings.json
plugins/FastAsyncWorldEdit/lang/ru-RU/strings.json
```

Обе папки — на всякий случай: FAWE берёт `lang/ru/strings.json` при
`default-locale: ru` и `lang/ru-RU/strings.json` при `default-locale: ru_ru`.

2. В `plugins/FastAsyncWorldEdit/worldedit-config.yml`:

```yaml
default-locale: ru_ru
```

3. `/fawe reload` или перезапуск сервера.

Если файла нет — сообщения просто остаются английскими, ошибок не будет.
Можно оставить в файле только нужные строки, остальные подтянутся из `en`.

## Цвета

Hex **не работает** в `strings.json` FAWE, хотя выглядит как рабочий код.

FAWE понимает только 16 ванильных цветов. Последовательность `§x§F§8§B§E§F§B`
он не разбирает: клиент видит `§x` как неизвестный код, пропускает его, а
применяет следующие подряд `§F`, `§8`, `§B`, `§E`, `§F`, `§B` — и в итоге
текст красится в **последний** цвет, `§B` (бирюзовый `#55FFFF`). Именно поэтому
раньше «ᴇʟʏᴛʀɪx» в префиксе стал бирюзовым.

Поэтому в файле только ванильные коды, а роль розового ElytriX играет `§d`
(светло-фиолетовый `#FF55FF`) — ровно тот код, что стоял в старом рабочем
`strings.json` в префиксе.

| Роль | Код |
|---|---|
| Розовый ElytriX (акценты, значения) | `§d` |
| Белый текст | `§f` |
| Серый / тёмный | `§7` / `§8` |
| Успех | `§a` |
| Ошибка | `§c` |

Если нужен именно `#F8BEFB` — в самом FAWE это недостижимо: hex в его
сообщениях не проходит. Ближайший ванильный цвет — `§d`.

## Префикс

```
§f☁ §dᴇʟʏᴛʀɪx §7» §f{0}
```

Так он выглядел в старом конфиге и так он снова выглядит.

## Что переведено

- `fawe.*` — 220 ключей: кисти, буфер обмена, схематики, история, подсказки, ошибки, лимиты, отмена правок.
- `worldedit.*` — 458 ключей: выделение, инструменты, генерация, снапшоты, side-эффекты, справка.
- `prefix`.

Старые формулировки сохранены там, где они уже были переведены, добавлены
все новые ключи (обновления FAWE, ограничения на число схематик, `//trim`,
`//cone`, `morph`-кисти, `arkitektonika`, `registry`, лимиты кисти и т.п.).
