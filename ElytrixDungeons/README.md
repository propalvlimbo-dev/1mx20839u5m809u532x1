# ElytrixDungeons

Совместимость: Paper 1.21.11.

## Собственные схемы

Плагин не генерирует и не поставляет схематики. Загрузите собственные `.schem` в соответствующие папки:

- `plugins/ElytrixDungeons/schematics/surface/` — наземные дома;
- `plugins/ElytrixDungeons/schematics/underground/` — подземные данжи.

Поставьте нужные контейнеры прямо в схему: наземные сундуки, бочки и шалкеры автоматически становятся точками лута; подземные контейнеры тоже обнаруживаются при загрузке схемы. Искусственные контейнеры не добавляются. После загрузки схем выполните `/edungeon reload`.

## Создание

- `/elytrixdungeon create surface <id-схемы>`
- `/elytrixdungeon create underground <id-схемы>`

Каждая команда создаёт один данж; максимум — семь каждого типа. Массовый автоспавн при первом запуске выключен. Первое место выбирается и данж создаётся вручную администратором.

## Наземный дом

Внутри дома появляется волна из шести призраков. Если убить всех шестерых, новая волна появляется сразу; иначе оставшиеся призраки заменяются через 30 минут после начала волны. С призрака всегда выпадает осколок, шанс ключа — 35%.

Найденные в схеме шалкеры получают случайную редкость от обычной до мифической; их цвет и имя показывают редкость. Содержимое и редкость каждого шалкера заново выбираются каждые шесть часов независимо от того, открывали ли контейнер. Для сглаживания края дома добавлен природный склон и редкие травяные пучки вокруг основания. Музыка `MUSIC_DISC_5` зацикливается, звучит с увеличенной дальностью внутри дома и останавливается при выходе.

## Координаты

Артефакт «Компас Правды» находится в BMenu → «Уникальные предметы» (слот 40, цена 2499 коинов). ПКМ показывает координаты случайного данжа в action bar в течение двух минут; перезарядка — два часа.
