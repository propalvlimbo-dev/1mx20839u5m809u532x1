# ElytrixDungeons

Совместимость: Paper 1.21.11.

## Собственные схемы

Плагин не генерирует и не поставляет схематики. Загрузите собственные `.schem` в соответствующие папки:

- `plugins/ElytrixDungeons/schematics/surface/` — наземные дома;
- `plugins/ElytrixDungeons/schematics/underground/` — подземные данжи.

Поставьте нужные контейнеры прямо в схему. Каждый обычный цветной шалкер в `.schem` служит маркером: при установке плагин заменяет его на шалкер с лутом в той же точке; сундуки и бочки также становятся точками лута. Для подземной схемы без шалкеров автоматически создаётся один запертый босс-шалкер. После загрузки схем выполните `/edungeon reload`.

## Создание

- `/elytrixdungeon create surface <id-схемы>`
- `/elytrixdungeon create underground <id-схемы>`

Каждая команда создаёт один данж; максимум — семь каждого типа. Массовый автоспавн при первом запуске выключен. Первое место выбирается и данж создаётся вручную администратором.

## Удаление данжа

Откройте `/edungeon gui`, затем в панели администратора нажмите **Shift+ЛКМ** по карточке нужного данжа. На экране подтверждения красная кнопка удалит данж и восстановит исходный рельеф по снимку, зелёная отменит действие. Вместе с данжем очищаются связанные призраки/мобы, голограммы, защита и сохранённые данные. Если снимок рельефа отсутствует или идёт установка/обновление, удаление не выполняется.

## Наземный дом

При появлении дома внутри размещаются до шести призраков в разных безопасных точках, вдали от входа. Убитые призраки пополняются по два каждые 60 секунд (максимум — шесть), а не появляются сразу всей новой толпой. С призрака всегда выпадает осколок, шанс ключа — 35%.

Голограмма автоматически выбирает свободное место комнаты с наибольшим запасом воздуха вокруг; для неё не используется блок шалкера. Найденные в схеме шалкеры получают случайную редкость от обычной до мифической; их цвет и имя показывают редкость. Содержимое и редкость каждого шалкера заново выбираются каждые шесть часов независимо от того, открывали ли контейнер. Для сглаживания края дома добавлен природный склон и редкие травяные пучки вокруг основания. Музыка `MUSIC_DISC_5` зацикливается, звучит с увеличенной дальностью внутри дома и останавливается при выходе.

## Координаты

Артефакт «Компас Правды» находится в BMenu → «Уникальные предметы» (слот 40, цена 2499 коинов). ПКМ показывает координаты случайного данжа в action bar в течение двух минут; перезарядка — два часа.
