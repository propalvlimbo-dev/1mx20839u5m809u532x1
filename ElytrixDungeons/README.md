# ElytrixDungeons

Совместимость: Paper 1.21.11.

## Собственные схемы

Плагин не генерирует и не поставляет схематики. Загрузите свои файлы `.schem` в соответствующие папки:

- `plugins/ElytrixDungeons/schematics/surface/` — наземные дома;
- `plugins/ElytrixDungeons/schematics/underground/` — подземные данжи.

После загрузки схем выполните `/edungeon reload`. ID схемы — имя файла без расширения. Подсказки с доступными ID появляются после выбора типа данжа.

## Создание

- `/elytrixdungeon create surface <id-схемы>`
- `/elytrixdungeon create underground <id-схемы>`

Каждый вызов создаёт один данж. Место подбирает `SpotFinder`; одновременно устанавливается только одна схема. Можно создать не более семи данжей каждого типа. Автоматическое массовое создание при первом запуске выключено.

В наземном доме появляется волна из шести призраков. Если убить всех, следующая шестёрка появляется сразу; иначе оставшиеся призраки заменяются новой волной через 30 минут после появления текущей. Внутри дома включается тревожная музыка. Над неоткрытыми контейнерами отображается подсказка «ОТКРЫТЬ»; после открытия она исчезает.
