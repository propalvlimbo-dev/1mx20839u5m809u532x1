# ElytrixDungeons

Совместимость: Paper 1.21.11.

## Собственные схемы

Плагин не генерирует и не поставляет схематики. Загрузите пользовательские `.schem` в соответствующие папки:

- `plugins/ElytrixDungeons/schematics/surface/` — наземные дома;
- `plugins/ElytrixDungeons/schematics/underground/` — подземные данжи.

Поставьте нужные контейнеры прямо в схему. Каждый цветной шалкер в наземной схеме служит маркером контейнера: после появления дома он получает лут, а его цвет и имя показывают редкость. Сундуки и бочки также становятся точками лута. В подземной схеме без шалкеров автоматически создаётся один запертый босс-шалкер. После загрузки схем выполните `/edungeon reload`.

## Создание и удаление

- `/elytrixdungeon create surface <id-схемы>`
- `/elytrixdungeon create underground <id-схемы>`

Каждая команда создаёт один данж; максимум — семь каждого типа. Массовый автоспавн при первом запуске выключен.

Для удаления откройте `/edungeon gui`, затем в панели администратора нажмите **Shift+ЛКМ** по карточке данжа и подтвердите действие. При удалении восстанавливается исходный рельеф; связанные мобы, голограммы, защита и сохранённые данные очищаются.

## Наземный дом

При появлении дома размещаются шесть призраков в коридорах первых двух этажей. Они летают ниже, а высота их перемещения корректируется по безопасным коридорным точкам. После убийства всей стаи начинается двухчасовой перерыв, затем появляется новая волна из шести призраков. С каждого призрака выпадает осколок; шанс выпадения ключа Хранилища — 35%.

При наличии нескольких шалкеров случайная половина (округление вниз) запечатывается. Лут помещается в каждый шалкер сразу при появлении дома. Для запечатанного шалкера подходит любой ключ Хранилища; ключ расходуется при успешном открытии, а его тип выбирает таблицу наград:

- `rusty` — обычная;
- `knowledge` — необычная;
- `royal` — редкая;
- `void` — эпическая;
- `unique` — мифическая.

Обычные ключи испытаний открывают шалкеры с эпическим лутом, зловещие ключи испытаний — с легендарным. Содержимое и редкость наземных шалкеров обновляются каждые шесть часов.

Небольшие голограммы показывают статус шалкеров и метку над призраками; общая голограмма всего данжа и подписи сундуков отключены. Игрокам внутри дома ActionBar в стиле Elytrix Auction показывает по очереди таймер полного сброса данжа, таймер обновления лута шалкеров и число оставшихся призраков — каждая тема сменяется через 15 секунд. Название отображается как «Данж».

По дому звучит мелодичная атмосферная дорожка `MUSIC_DISC_OTHERSIDE`, а не пугающие звуковые эффекты. Она запускается каждому игроку отдельно, поэтому не зависит от расстояния до одной точки, зацикливается и останавливается при выходе. Точка безопасного телепорта находится на первом этаже.

## Координаты

Артефакт «Компас Правды» находится в BMenu → «Уникальные предметы» (слот 40, цена 2499 коинов). ПКМ компасом в воздухе показывает координаты случайного данжа в ActionBar в течение двух минут; перезарядка — два часа.
